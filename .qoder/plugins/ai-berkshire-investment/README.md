# AI Berkshire Investment Skills

Qoder-native plugin containing 20 value investing research skills.

## Skills (20)

### 筛选类
- **industry-funnel**: 行业漏斗筛选 — 从全市场到3家的价值投资精选流程
- **quality-screen**: 去劣筛选 — 7条指标快速排除非一流公司
- **bottleneck-hunter**: 供应链瓶颈猎手 — AI驱动的全球产业链瓶颈套利

### 个股深度研究
- **investment-team**: 投研团队 — 四角色(段永平/巴菲特/芒格/李录)并行分析框架
- **investment-research**: 投资研究 — 巴菲特-芒格-段永平-李录四大师综合分析
- **investment-checklist**: 巴菲特价值投资买入前 Checklist — 六关验证
- **deep-company-series**: 深度公司系列 — 3-8篇长文拆解一家公司

### 行业研究
- **industry-research**: 行业投资研究 — 产业链全景扫描+四大师个股分析框架

### 管理层与风险
- **management-deep-dive**: 管理层纵深研究 — 买股票就是买人
- **thesis-drift**: 投资论文漂移检测 — 分清事实变化与措辞变化
- **thesis-tracker**: 投资论文追踪 — 买入后的纪律系统

### 财报与数据
- **earnings-review**: 财报精读 — 一手资料深度解读
- **earnings-team**: 财报精读团队 — 四大师并行解读+公众号发布
- **financial-data**: 财务数据获取与交叉验证规范

### 组合管理
- **portfolio-review**: 组合管理 — 从研究公司到管理组合
- **income-investment**: 收入投资 — 持久和机会性分配分析

### 其他
- **dyp-ask**: 段永平问答 — 以他的方式思考投资问题
- **news-pulse**: 新闻脉搏 — 快速扫描投资相关新闻
- **private-company-research**: 未上市公司研究 — 多Agent并行深度研究框架
- **wechat-article**: 微信公众号文章 — 作者-编辑-读者三Agent协作
