### 四大师方法论融合
- 定义：AI Berkshire 的核心投资研究框架，将巴菲特（护城河、安全边际、管理层）、芒格（逆向思考、风险清单、偏误自查）、段永平（商业模式本质、对的生意）、李录（文明趋势、范式转移、产业价值）四位价值投资大师的思维方式进行系统化融合，通过多Agent对抗产生真实矛盾和张力，避免单一视角盲点。
- 别名：四大师视角对抗、四大师综合分析

### Skill 层
- 定义：AI Berkshire 三层架构中的用户接口层，将投资研究需求抽象为19个明确入口，包括深度研究类（/investment-research、/investment-team等）、财报分析类（/earnings-review、/earnings-team等）、行业筛选类（/industry-research、/industry-funnel等）、持仓管理类（/portfolio-review、/thesis-tracker等）、思维工具类（/dyp-ask、/financial-data等）。
- 别名：Skills 一览、19个Skill

### Team Lead
- 定义：团队型 Skill 中的协调角色，负责并行调度4个大师视角 Agent（分别代表段永平、巴菲特、芒格、李录），各自独立搜索、独立判断、互相挑战，最后综合研判形成最终结论。轻量 Skill 不经过这一层，直连工具快进快出。
- 别名：投研团队协调者

### 镜子测试
- 定义：投资决策纪律检查机制，要求投资者用5句话完整说明买入理由：理解生意本质、识别护城河、评估管理层、计算安全边际、控制下行风险。如果5句话说不完整 = 不买，没有例外。这是防止冲动投资和确保决策理性的关键约束。
- 别名：五句话测试、5句话说不完整

### 信息丰富度评级
- 定义：AI研究偏见自觉机制，对研究资料进行A/B/C三级评级，防止"资料多=确定性高"的幻觉。B级表示数据有限，推算指标需标注置信度；C级表示信息极度稀缺，需要更多谨慎处理。
- 别名：A/B/C级信息丰富度评级、信息质量评级

### 芒格式逆向检验
- 定义：结构化反偏见机制之一，强制思考失败场景，典型问题是"什么情况下[公司]会死？"，列出多种失败情景及概率。这是芒格"反过来想"思维方式的程序化实现，用于发现被忽视的风险。
- 别名：逆向思考、失败场景分析

### 快速否决清单
- 定义：8条红线一票否决机制，当公司存在管理层诚信污点等严重问题时，无论估值多么便宜都直接否决。这是投资纪律的硬性约束，防止因价格诱惑而忽略根本性风险。
- 别名：一票否决清单、8条红线

### 反共识检查
- 定义：避免和市场想法一样的防御机制，通过提问"聪明人为什么在做空？"来发现被市场忽视的风险。这是对抗群体思维和确认偏误的重要工具。
- 别名：反向思考、市场异见分析

### 留白原则
- 定义：宁可说"不知道"的研究纪律，当数据不足时标注"灰色地带"，不用推测伪装确定性。这是防止过度自信和虚假确定性的重要原则。
- 别名：灰色地带标注、不确定性承认

### 金融严谨性工具
- 定义：tools/financial_rigor.py 提供的精确计算工具集，包括市值验算（verify-market-cap）、估值验算（verify-valuation）、多源交叉验证（cross-validate）、三情景估值（three-scenario）、Benford定律检测（benford）、精确计算器（calc）。所有计算使用 Python decimal.Decimal 而非 float，确保金融计算的精确性。
- 别名：financial_rigor.py、财务验算工具

### 产业链全景扫描
- 定义：/industry-research Skill 的核心功能，从一个投资主题出发，完成投资逻辑链构建 → 产业链全景图 → 全球上市公司扫描 → 各环节头部公司四大师分析 → 投资组合配置建议的完整研究流程。按产业链环节切片分析，区别于个股筛选漏斗。
- 别名：产业链研究、行业全景分析

### 行业漏斗筛选
- 定义：/industry-funnel Skill 的逐层精选流程：全市场扫描（活跃度+涨幅+市值前30并集，30-60家）→ 粗筛≤10家 → 精细分析 ≤10家 → 终选3家深度分析。终选按"组合互补性"选择（高确定性+中等弹性+高弹性），不按打分前3排序，并强制列"未来IPO候选"。
- 别名：全市场筛选漏斗、三阶段筛选

### 未上市公司深度研究
- 定义：/private-company-research Skill 专为信息稀缺的未上市公司设计的"侦探式"研究框架，核心差异化包括：财务数据拼凑（从招股书、母公司财报、融资新闻、行业数据多源拼凑）、置信度标注（每个数据点标注🟢高/🟡中/🔴低置信度）、多方法估值交叉（融资估值法+可比公司法+DCF+终局倒推法）、退出路径分析（IPO/并购/二级转让全路径评估）。
- 别名：非上市公司研究、暗资产研究

### 股价异动快速归因
- 定义：/news-pulse Skill 专为"股价大涨/大跌时快速搞清发生了什么"设计的情报响应工具，不是深度投研而是10-15分钟的快速归因。核心特色包括：4维并行侦察（公司事件/监管政策/行业对手/市场情绪）、归因优先于罗列、强制性质判断（价值事件/情绪波动/真因不明/混合）、明确行动建议。
- 别名：异动归因、新闻归因分析

### 投资论文追踪
- 定义：/thesis-tracker Skill 的买入后纪律系统，持续跟踪投资论文是否被证伪。配合 /thesis-drift 投资论文漂移检测，对比两份论文/报告，区分事实变化、估值变化与措辞变化，确保投资决策的持续有效性。
- 别名：thesis-tracker、投资论点跟踪

### 微信公众号文章协作
- 定义：/wechat-article Skill 的作者、编辑、读者三Agent协作工作流，产出可发布的微信公众号文章。这是AI Berkshire研究成果对外传播和内容分发的核心渠道，与"复利炼丹炉"公众号形成闭环。
- 别名：wechat-article、公众号文章生成
