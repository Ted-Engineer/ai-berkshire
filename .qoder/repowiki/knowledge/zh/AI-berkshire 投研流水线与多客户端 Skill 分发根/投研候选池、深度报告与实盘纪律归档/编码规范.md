- 筛选结果按“编号-行业”命名（如 `01-食品饮料.md`），并在同目录 README 中以表格汇总全部候选公司及其代码与核心业务。
- 个股研究采用“公司名/股票代码”独立子目录组织，每家公司积累多轮 checklist、team-checklist、investment-team-checklist 等渐进式文件。
- 交易纪律文件对每只持仓分别定义“证伪即卖”和“触发重审”两类条件，并给出估值离谱线（PE/市值阈值）与对应买入论文引用。
- 自动化扫描脚本将每一步筛选/指标取值记录为结构化 round（type: screen/metric），统一追加到 `rounds.jsonl` 以便回溯评估过程。
- 汇总报告使用带日期的文件名（如 `portfolio-action-20260812.md`、`FINAL-唯二-20260809.md`）体现版本演进，并以 JSON 文件（`final-rank.json`、`pairwise-v*.json`、`audit_*.json`）承载机器可读的排序与比对结果。
