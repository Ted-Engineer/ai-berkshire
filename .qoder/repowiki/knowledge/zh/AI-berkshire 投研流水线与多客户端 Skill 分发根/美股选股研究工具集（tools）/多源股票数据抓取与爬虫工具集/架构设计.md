模块由一组彼此独立的 CLI 脚本组成，每个文件对应一个数据源或任务，无共享库：
- 美股实时/历史报价：`fetch_quotes.py`（直调 Yahoo Finance v8/v10）、`fetch_v2.py`/`realtime_fetch.py`（基于 yfinance）、`finviz_quote.py`/`sa_quote.py`（HTML 解析作为交叉验证）、`morningstar_fair_value.py`（Morningstar screener API）。
- A股数据：`ashare_data.py` 通过 `subprocess` 调用 `/usr/bin/curl --noproxy *` 直连腾讯行情与东方财富 datacenter，提供 quote/financials/valuation/search 子命令。
- 台股数据：`twstock_data.py` 封装 FinMind 开放 API，按 token 优先级（环境变量 > local/finmind_token.txt）访问，提供 quote/valuation/financials/revenue/dividend/search 子命令。
- 组合编排：`fetch_candidate_pool.py` 以批（6只）方式 subprocess 调用 `fetch_quotes.py` 并合并手动价格写入 `data/candidates/`。
- 非结构化内容：`xueqiu_scraper.py` 基于 Playwright 异步爬取雪球用户时间线，支持 headful 登录态持久化、断点续爬、关键词过滤与 Markdown 输出。
所有脚本均以 `if __name__ == '__main__'` 暴露命令行入口，对外仅通过 JSON/stdout 或本地文件交换数据，不互相 import。
