- 每个数据源封装为独立可执行脚本，通过 `argparse` 或 `sys.argv` 接收 ticker/code/keyword，并以 JSON 或格式化文本输出结果。
- 外部网络请求统一使用 try/except 包裹，失败时返回包含 `'error'` 字段的字典，并将进度日志打印到 stderr。
- 对第三方网站采用 User-Agent 伪装与随机 sleep（0.3~4s）降低限流风险，Finviz/SA 等 HTML 抓取使用正则提取字段。
- 敏感凭据（FinMind token、雪球账号）仅从环境变量或本地 gitignore 目录读取，不硬编码进代码。
- A 股与台股工具通过 `subprocess` 调用 curl 直连上游 API，绕过系统代理以保证稳定性。
- 长耗时爬取（雪球时间线）实现断点续爬：每 N 页保存 progress JSON，中断后自动从上次页码继续。
