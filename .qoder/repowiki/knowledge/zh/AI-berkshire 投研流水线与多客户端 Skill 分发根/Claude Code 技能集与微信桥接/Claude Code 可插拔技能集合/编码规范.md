- 每个技能目录统一包含 `agents/openai.yaml` 与 `SKILL.md`，前者声明 display_name/short_description 等元数据，后者以 YAML front-matter 声明 name/description/allowed-tools 等元数据。
- SKILL.md 正文采用层级标题（##、###）+ 编号步骤的结构化提示词，明确触发条件、前置检查、执行顺序与失败分支。
- 复杂技能将辅助文档拆分为独立 Markdown（如 DESIGN-IT-TWICE.md、ADR-FORMAT.md、references/*.md），由主 SKILL.md 通过相对路径引用，避免单文件膨胀。
- 需要外部交互的技能通过 `scripts/` 目录放置 shell 模板或守护脚本，由 SKILL.md 中的命令片段调用。
- 技能间通过斜杠命令（/grilling、/research、/prototype、/wayfinder 等）进行协作，而非直接 import 或文件共享，保持松耦合。
- 对网络/环境敏感的操作在 SKILL.md 中显式列出安全规则与回退策略，要求先探测状态再执行高风险动作。
