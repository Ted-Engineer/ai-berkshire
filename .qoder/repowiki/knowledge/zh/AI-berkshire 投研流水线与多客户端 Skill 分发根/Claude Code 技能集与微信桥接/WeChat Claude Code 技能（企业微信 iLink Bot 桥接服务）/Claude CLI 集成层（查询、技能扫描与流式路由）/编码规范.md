- 流式解析逻辑抽离为纯函数（如 `handleStreamLine`）并通过回调接口（`onText`/`onTurnEnd`）解耦 I/O，便于单元测试。
- 对外暴露的异步入口统一返回包含 `text`、`sessionId`、可选 `error` 的结构化结果对象，错误信息集中聚合在 error 字段而非抛出异常。
- 文件系统访问采用 try/catch 包裹并以空集合或 null 降级返回，保证单个目录不可读不影响整体扫描。
- 状态机类（如 `TurnRouter`）不直接执行 I/O，仅维护内部缓冲并通过构造函数注入的 emit 回调向上层推送消息。
- 噪声过滤与格式判定全部基于正则表达式与长度阈值等结构特征，避免引入外部解析器以保持轻量。
