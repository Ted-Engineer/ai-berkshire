skills/ 下按领域并列存放数十个独立技能目录，每个技能自包含 SKILL.md（任务流程、工具、输出格式）与 agents/openai.yaml（模型参数），由上层 Claude Code 在启动时扫描发现并加载；所有技能共享同一加载契约，使宿主无需感知具体实现即可切换执行。wechat-claude-code 是唯一具备完整运行时（TypeScript + Node.js）的子工程，作为独立进程运行，负责轮询企业微信 iLink Bot 消息、流式路由到对应 skill 的指令，从而把外部聊天入口与内部技能编排连接起来。根目录下的扁平 *.md 文件（如 daily-brief.md、investment-research.md 等）提供可直接引用的 Prompt 片段，供组合或单独调用。
