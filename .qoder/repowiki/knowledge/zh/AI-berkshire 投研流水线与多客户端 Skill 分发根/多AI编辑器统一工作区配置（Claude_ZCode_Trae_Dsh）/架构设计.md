本模块由四个并列的隐藏目录组成，分别对应不同 AI 编辑器的原生配置约定：
- `.claude/`：Claude Code 主工作区，包含 `settings.json`（通过 SessionStart hook 注入 `.learnings/` 知识库摘要）、`commands/`（按主题划分的 Markdown 命令模板）、`skills/`（每个技能一个目录，内含 `SKILL.md` 与可选 `agents/openai.yaml`、`scripts/`、`references/` 等扩展资源）、`hooks/`（JS/Shell 钩子脚本）、`workflows/` 与 `.workflow/`。
- `.zcode/config.json`：ZCode 的完整钩子编排，覆盖 SessionStart、UserPromptSubmit、PostToolUse（按 matcher 区分 Skill/Write/WebSearch 等工具调用）、Stop 等事件，统一调用仓库根 `scripts/*.sh` 完成技能执行追踪、搜索记录、工作流清理与安全门禁。
- `.trae/skills/` 与 `.dsh/skills/`：仅保留精简版 `SKILL.md` 文件，作为 Trae 与 Dsh 的轻量技能集，与 `.claude/skills/` 中的同名技能形成“核心定义 + 多端复用”的关系。
依赖方向单向：各编辑器配置 → 仓库根 `scripts/*.sh` 执行实际逻辑；技能之间无相互引用，全部以独立目录自描述。
