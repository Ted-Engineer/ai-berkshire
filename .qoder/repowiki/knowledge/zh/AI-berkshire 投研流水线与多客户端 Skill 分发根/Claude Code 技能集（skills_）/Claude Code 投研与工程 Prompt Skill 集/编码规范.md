- 每个技能目录遵循 `SKILL.md` + `agents/openai.yaml` 的双文件约定，front matter 中声明 name/description，必要时设置 `disable-model-invocation: true` 或 `allow_implicit_invocation: false`。
- 工程类技能通过读取 `docs/agents/*.md`（issue-tracker、domain、triage-labels）获取目标仓库约定，而非硬编码路径，使同一套技能可在不同仓库复用。
- 投研相关文档将分析步骤拆分为编号阶段（第一步至第八步），每阶段末尾附带对应大师的“追问”段落，强制反思性输出。
- 所有涉及数值计算的部分必须通过 `tools/financial_rigor.py` 命令行工具执行，禁止 LLM 心算，并在报告中附录验算过程。
- 报告发布前必须执行 `report_audit.py` 的 15% 随机抽检流程，偏差超过 1% 即打回修正，形成准出门禁。
- WeChat 桥接子技能按职责划分 src 子目录（claude、commands、wechat、tools、tests），并通过独立的 package.json 管理依赖与 build/test/daemon 脚本。
