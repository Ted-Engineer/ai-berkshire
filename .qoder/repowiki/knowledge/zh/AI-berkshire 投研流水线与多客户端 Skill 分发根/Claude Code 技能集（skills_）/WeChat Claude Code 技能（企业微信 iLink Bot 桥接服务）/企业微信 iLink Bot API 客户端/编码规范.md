- 对外 HTTP 请求统一通过 `WeChatApi.request<T>` 发起，集中处理 JSON 序列化、超时 AbortController、错误包装与日志记录。
- 所有外部 I/O（fetch、fs、网络）均包裹 try/catch 并使用 `logger` 输出结构化日志，错误时返回 null 或抛出语义化 Error。
- 长轮询与定时任务通过 `AbortController` + 自定义 `sleep(signal)` 实现可中断的等待，便于优雅停止 monitor 与 typing keepalive。
- 对易失败的远端调用采用固定次数重试 + 指数退避策略（sendMessage 最多 2 次重试，CDN 上传最多 3 次）。
- 敏感配置（token、aesKey）以独立字段存储并通过类型约束（如 `AccountData`、`GetUploadUrlReq`）在 `types.ts` 中集中声明。
- 对速率限制与异常状态采用显式状态机：`api.ts` 用熔断器（circuit breaker）+ 用户级冷却 Map，`monitor.ts` 用连续失败计数触发短/长退避。
