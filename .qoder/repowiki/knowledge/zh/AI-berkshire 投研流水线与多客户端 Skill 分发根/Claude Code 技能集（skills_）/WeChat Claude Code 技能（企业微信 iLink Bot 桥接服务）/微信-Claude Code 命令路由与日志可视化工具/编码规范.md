- 命令处理器统一接收 `CommandContext` 并通过返回 `{ handled, reply|claudePrompt|sendFile }` 的 `CommandResult` 对象表达处理结果，由 router 统一消费。
- 新增命令采用「router 中 switch 分支 + handlers 中同名 `handleXxx` 函数」的双文件拆分模式，便于扩展而不改动路由逻辑。
- 对易变资源（如 skill 列表）使用模块级缓存加 TTL（60s）策略，并提供 `invalidateSkillCache` 暴露强制刷新能力。
- CLI 工具以顶层 `parseArgs` → 数据处理管线 → `generateHtml` → `main()` 的顺序组织，各阶段函数职责单一且可单独测试。
- 日志解析采用「逐行正则匹配 → 提取 JSON 片段 → tryParseJson 容错」的三段式结构，以应对 redact() 导致的损坏 JSON。
