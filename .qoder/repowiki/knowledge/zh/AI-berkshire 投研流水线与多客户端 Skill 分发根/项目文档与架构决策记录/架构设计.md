本模块为纯文档仓库，按主题分层组织：
- `docs/` 根目录包含顶层规划文件：`ROADMAP.md` 定义 P0/P1/P2 三阶段产品路线；`spec-saas-mvp.md` 作为 SaaS 子项目的完整规格，涵盖用户故事、技术栈（Spring Boot + Python Worker + Next.js）、密钥状态机、Redis Pub/Sub 编排流程、API 契约及测试策略。
- `docs/adr/` 采用编号前缀的 ADR 格式（0001-0003），记录关键架构决策如 SaaS 架构、Claude Agent SDK over CLI、预付密钥免注册方案。
- `docs/agents/` 聚焦 Agent 层治理：`domain.md` 描述业务域模型，`issue-tracker.md` 与 `triage-labels.md` 定义 Issue 分类与标签体系。
- `research/` 存放研究性笔记，如 `MU_memory_supercycle_2026-08-08.md`。
该模块不产出可执行代码，仅通过 Markdown 文档驱动跨仓库（ai-berkshire 与 ai-berkshire-saas）的协作与演进。
