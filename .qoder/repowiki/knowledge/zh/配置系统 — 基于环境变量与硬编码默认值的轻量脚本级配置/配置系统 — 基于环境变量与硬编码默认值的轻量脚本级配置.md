本仓库为投研知识库与工具脚本集合，并未引入统一的配置框架（如 pydantic-settings、dotenv、configparser、TOML/YAML 集中式配置文件等）。运行时配置以“每个脚本各自读取环境变量 + 内置默认值”的轻量方式实现，遵循“凭据不进仓库、通过环境注入”的原则。

1. 使用的系统与模式
- 无集中式配置目录或配置文件：仓库中不存在 `config/`、`.env`、`application.properties`、`settings.yaml` 等统一入口。
- 采用 Python 标准库 `os.environ.get()` 直接读取环境变量，并在缺失时回退到硬编码默认值或直接提示交互登录。
- 登录态等敏感状态以本地 JSON 文件缓存（`/tmp/xueqiu_state.json`），被 `.gitignore` 显式排除，避免入库。

2. 关键文件与位置
- tools/ashare_data.py：通过 `EASTMONEY_SEARCH_TOKEN` 环境变量覆盖东方财富搜索 token，未设置时使用公开默认值。
- tools/xueqiu_scraper.py：通过 `XQ_PHONE` / `XQ_PASSWORD` 环境变量传入雪球账号凭据；若未提供则启动 headful 浏览器引导手动扫码登录，并将登录态持久化到 `/tmp/xueqiu_state.json`。
- .gitignore：明确忽略 `/tmp/xueqiu_state.json`、`/local/` 以及各类音视频大文件，保证凭据与本地产物不进入版本控制。

3. 架构与约定
- 配置粒度：按独立脚本划分，每个脚本自行声明所需的环境变量名及默认行为，不存在跨模块共享的配置加载器。
- 分层策略：
  - 安全凭据（如 XQ_PHONE/XQ_PASSWORD）必须通过环境变量注入，禁止写入代码或提交到仓库。
  - 非敏感参数（如东方财富公开 token）允许在代码中给出可工作的默认值，同时支持通过环境变量覆盖。
  - 会话/状态类数据（cookies、进度、全量缓存）落盘到 `/tmp` 或 `--state-path` 指定路径，由脚本生命周期管理。
- 运行期发现：当关键凭据缺失时，脚本会打印清晰的提示信息并进入交互式流程（打开浏览器完成登录），而非静默失败。

4. 开发者应遵循的规则
- 新增外部依赖凭据时，一律使用 `os.environ.get("VAR_NAME", "")` 形式读取，并在文档注释中说明对应环境变量名。
- 不要将任何密码、token、cookie 写入源码或随仓库提交；如需演示默认值，请确保其仅用于公开接口且不影响安全性。
- 需要持久化的登录态/进度文件统一放在 `/tmp` 或通过 CLI 参数指定路径，并确保被 `.gitignore` 覆盖。
- 若未来需要引入集中式配置（如多服务共享密钥、Feature Flag），建议优先评估 pydantic-settings + `.env` 方案，保持当前“环境变量优先”的注入风格不变。
