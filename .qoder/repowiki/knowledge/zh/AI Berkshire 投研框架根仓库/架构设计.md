根目录作为 Skill 分发中心与流水线编排层：`skills/*.md` 是唯一的权威工作流定义，由 `scripts/sync-codex-skills.py`、`scripts/sync-trae-skills.py`、`scripts/sync-dsh-skills.py` 分别生成 `codex-skills/`、`.trae/skills/`、`.dsh/skills/` 下的可执行包；Claude Code 直接读取 `skills/*.md` 并通过 `CLAUDE.md` 行为配置，Codex 额外提供 `codex-prompts/` 斜杠提示兼容层。所有客户端共享同一套工具链 `tools/*.py`（如 `financial_rigor.py`）和研究报告输出目录 `reports/`，从而保证不同 Agent 环境产出的数据校验标准与报告格式一致。顶层 `CONTEXT.md` 定义了面向 SaaS Worker 的编排语义（研报套餐、配额扣减），将本仓库的技能能力封装为 Python SDK 可调用的服务。各子模块按职责切分：`stock_screening_tools` 提供数据抓取与筛选脚本，`research_scripts` 提供漏斗筛选与回归测试等辅助脚本，`agent_skills` 组织可插拔 Skill 描述，`documentation` 沉淀 ADR 与规范，`investment_data_artifacts` 归档产出物与实盘记录，根级文档与脚本则负责把它们串联成可复现的研究流水线。
