模块以 `skills/<skill-name>/` 为单位组织每个独立技能，统一采用两层结构：顶层 `SKILL.md` 通过 YAML front matter（name/description/disable-model-invocation）声明元数据并描述任务流程；子目录 `agents/openai.yaml` 暴露 `interface.display_name`、`policy.allow_implicit_invocation` 等运行时接口与策略。根目录下散落一批面向投资主题的纯 Markdown 提示词（如 earnings-review、quality-screen、thesis-drift），作为无 agent 配置的轻量 Prompt Skill。工程类技能（code-review、implement、triage、tdd、qa 等）依赖 `setup-matt-pocock-skills` 在目标仓库生成的 `docs/agents/*.md`（issue-tracker、domain、triage-labels）作为共享约定，形成配置驱动的技能协作面。投研流水线由 `investment-research.md` 编排，强制调用 Python 工具 `tools/financial_rigor.py`、`tools/report_audit.py`、`tools/twstock_data.py` 完成市值验算、三情景估值与 15% 随机抽检，输出写入 `~/[公司名]投资研究报告.md`。唯一包含完整 TypeScript 工程的子技能是 `wechat-claude-code/`，其 `src/` 下按 claude/provider、commands/router、wechat/*、tools、tests 分层，通过 `package.json` 的 build/start/test/daemon 脚本运行，并以 `scripts/daemon.sh` 守护进程形式集成到 Claude Code 会话。
