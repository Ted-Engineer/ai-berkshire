本模块围绕 `claude` CLI 构建四层协作：
- `provider.ts`：核心入口，使用 `node:child_process.spawn` 启动 `claude -p - --output-format stream-json ...`，通过 `readline` 逐行解析 stdout 的 NDJSON，按 `system/assistant/stream_event/result` 等 type 分发到纯函数 `handleStreamLine`；支持图片 base64 转临时文件注入 prompt、`AbortController` 取消、60 分钟超时、会话 ID 追踪与错误聚合。
- `skill-scanner.ts`：递归扫描 `~/.claude/skills`、`~/.claude/plugins/cache/{plugin}/skills`、`superpowers/skills` 目录，正则提取 `SKILL.md` 的 YAML frontmatter 中 `name/description`，去重后提供列表格式化与名称匹配。
- `turn-router.ts`：无 I/O 的状态机，依据 `stopReason` 将文本分流为 `interstitial`（tool_use 中间结果）与 `final`（最终答案），并在 `drain()` 时合并残留缓冲。
- `tool-noise-filter.ts`：基于结构特征（长度阈值 + ```json``` 围栏 + URL/绝对路径）识别第三方代理塞入的工具噪音，仅保留尾部人类可读旁白并加 `🔧 [工具调用]` 前缀。
依赖方向单向向外：各文件均只依赖 Node 内置 API 与上层 `../logger.js`，彼此之间无耦合，由上层 `main.ts` 组合调用。
