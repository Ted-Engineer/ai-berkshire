测试目录采用按被测模块划分的扁平结构：`provider.test.ts` 验证 `../claude/provider.js` 的 `handleStreamLine` 对 system init、content_block_delta、message_delta 等 stream_event 的状态机行为；`turn-router.test.ts` 通过构造 `TurnRouter` 实例并收集回调，断言 `onText`/`onTurnEnd`/`drain` 组合下 interstitial 与 final 消息的聚合与拼接逻辑；`tool-noise-filter.test.ts` 直接读取 `fixtures/tool-noise/real-cases.json` 中的真实日志样本，验证 `filterToolNoise` 将超长 JSON 工具转储压缩为 `🔧 [工具调用]` 前缀的行为。`fixtures/tool-noise/extract-fixtures.mjs` 是独立的一次性脚本，从本地 bridge 日志中提取命中与正常样本生成 fixture，供回归测试复用。所有测试均使用 Node 内置 `node:test` 与 `assert/strict`，不依赖第三方测试框架。
