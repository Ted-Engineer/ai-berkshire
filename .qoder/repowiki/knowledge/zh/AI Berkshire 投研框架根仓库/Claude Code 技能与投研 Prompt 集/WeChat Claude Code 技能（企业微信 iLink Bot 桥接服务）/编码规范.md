- 所有对外部服务的调用（iLink HTTP、Claude CLI、文件系统）均通过 `logger.ts` 记录结构化日志，错误路径统一 catch 并降级返回友好提示。
- 跨模块共享的状态（账号、会话、配置、待发送队列）统一通过 `store.ts` / `session.ts` / `config.ts` / `pending-queue.ts` 的读写函数访问，避免直接操作磁盘文件。
- 流式响应按段落拆分并通过 `splitMessage` 控制在 4000 字符内分批推送，失败内容进入 pending queue 等待下次上下文刷新时重试，保证“不静默丢弃”。
- 子模块之间通过构造函数注入依赖（如 `createSender`、`createMonitor`、`createSessionStore`），而非全局单例，便于测试中替换为 mock。
