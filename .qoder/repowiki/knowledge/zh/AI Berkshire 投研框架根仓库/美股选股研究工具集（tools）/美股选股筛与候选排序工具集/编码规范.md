- 每个脚本均为独立可执行入口，通过 `if __name__ == '__main__': main()` 启动，并支持命令行参数（如 `--out`、ticker 列表）。
- 数据持久化采用 JSON 文件落盘至 `data/` 或 `reports/` 目录，文件名常带日期后缀（如 `20260809`）以便版本追踪。
- 外部数据源统一通过 HTTP 请求封装（requests.Session + User-Agent 伪装），并对 429/502/503 等错误进行重试与退避。
- 排序逻辑统一采用冒泡式两两比较（n*(n-1)/2 次比较），按 composite_score 或六维度逐项 PK 后降序排列。
- 数值字段解析采用容错函数（如 parse_num、parse_pe），将空值、'-'、'N/A'、NaN 等异常统一映射为默认值后再参与计算。
- 多版本迭代脚本通过文件名后缀区分（v2/v4/v5/fresh/portfolio），保留历史版本而非覆盖，便于回溯不同评分策略的结果。
