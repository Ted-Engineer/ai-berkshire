本模块由一组相互独立的 Python 脚本组成，按数据获取→初筛→深度研究→排序的流水线组织：
- 数据获取层：`stock_screener.py` 通过 curl 调用 Yahoo Finance v8 日线接口取价格；`mega_scan.py`、`rigorous_screen.py`、`full_market_scan.py` 分别通过 Yahoo v10 quoteSummary（带 crumb）、SEC EDGAR XBRL facts API、finviz 爬虫抓取基本面/估值/行情数据，统一产出 JSON 落盘 `data/`。
- 初筛层：`stock_screener.py` 实现两层筛选——60日新高+放量确认的动量发现，以及基于财报季度数据的6维价值验证（营收加速、毛利率改善、EPS超预期等），信号分三级仓位。
- 深度研究与报告聚合：各子 Agent 生成 `reports/*-funnel-*.md`、`*-bottleneck-*.md`、`*-team-checklist-20260809.md` 等 Markdown 报告，后续脚本通过正则解析评分。
- 排序层：`bubble_rank.py`、`candidate_ranker.py`、`final_bubble_rank.py`、`final_bubble_v4.py`、`final_bubble_rank_v2.py`、`fresh_bubble_v5.py`、`portfolio_bubble_0810.py`、`screen5.py`、`recheck_rank.py`、`tiebreak2.py`、`montecarlo_5000_screen.py` 等脚本围绕同一核心思想——对候选池做 n*(n-1)/2 轮冒泡式两两比较，依据综合评分或六维度（段永平/巴菲特/芒格/李录/清单/市值）逐场 PK，选出唯二候选。
依赖方向单向：数据获取脚本 → 初筛脚本 → 报告文件 → 排序脚本，排序脚本之间无相互 import，仅共享 `data/` 与 `reports/` 文件系统约定。
