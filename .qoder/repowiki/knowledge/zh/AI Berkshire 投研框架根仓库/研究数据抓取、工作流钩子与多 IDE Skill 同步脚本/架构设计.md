本模块按职责划分为四类独立脚本，彼此无相互依赖：
- 研究与分析脚本（`fetch_stocks.py`、`funnel_analysis.py`、`funnel_round2.py`、`append_rounds.py`、`write_report.py`）：通过 `yfinance` 拉取 Yahoo Finance 行情，执行四段式漏斗筛选（全市场扫描→瓶颈猎手→5条硬指标粗筛→精细对比），最终输出 Markdown 研究报告。
- 工作流钩子与安装脚本（`workflow-gate-hook.sh`、`workflow-cleanup-hook.sh`、`workflow-session-cleanup.sh`、`skill-enforcement-hook.sh`、`skill-tracker-hook.sh`、`search-tracker-hook.sh`、`learnings-digest.sh` 及 `install-*.sh/.bat`）：基于 `.claude/.workflow` 下的命名约定文件（`active`、`investment-team-*.done`、`candidates.csv`、`search-log.txt`、`recommended-buys.txt` 等）实现关卡校验、会话清理与 Skill 强制约束；同时把 `skills/`、`codex-prompts/` 等目录同步到各 IDE 的约定路径。
- 跨平台同步脚本（`sync-codex-skills.py`、`sync-codex-prompts.py`、`sync-dsh-skills.py`、`sync-trae-skills.py`、`sync-zcode-skills.py`、`sync-qoder-skills.py`、`sync-dsh-skills.py`）：以 Python 解析源 Skill/Prompt 的 YAML front matter，生成目标格式并支持 `--check` 只读校验模式，保证多工具间单一事实源。
- 测试（`tests/test_financial_rigor.py`、`test_report_audit.py`）：使用标准库 `unittest`，通过设置 `PYTHONIOENCODING=gbk` 模拟 Windows 控制台环境调用 `tools/financial_rigor.py`，确保 Unicode 输出不崩溃且计算逻辑不变。
依赖方向单向：测试 → tools；安装/同步脚本 → skills/codex-* 目录；研究脚本 → Yahoo Finance / 本地 JSON；钩子脚本仅读写 `.claude/.workflow` 状态文件，彼此通过约定文件名协作。
