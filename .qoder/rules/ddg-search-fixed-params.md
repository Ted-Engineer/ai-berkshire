# ddg-search MCP search 工具固定参数规则

每次调用 ddg-search MCP 的 `search` 工具时，**必须**传入以下固定参数，不得使用其他值或省略：

## 固定参数

- `max_results`: **20**（永远固定）
- `region`: **"us-en"**（永远固定，美国/英文）

## 示例

```json
{
  "query": "...",
  "max_results": 20,
  "region": "us-en"
}
```

## 例外

仅当用户在当前对话中明确要求修改这两个参数（如「这次用 10 条」「搜中文结果」）时，才按用户临时指定的值调用；用户未指定时一律使用上述固定值。
