# 投研团队：四角色并行分析框架

对 $ARGUMENTS 进行团队化投资研究分析。使用 Team 工具创建真正的多Agent并行研究团队。

## 模式选择（v7.1 新增——先判定，再组建团队）

**在创建团队之前必须先判定本次研究的时间口径**，它决定四个角色问什么问题。判定顺序：

1. **调用方显式指定** → 以指定为准。`/investment-team TICKER tactical` 或 `1-12m` → **战术模式**。
2. **调用方是 `portfolio-rebalance` / `daily-brief` / `portfolio-review` / `news-pulse`** → **默认战术模式**（这些框架的用户指令期限是 1-12 个月）。
3. **调用方是 `deep-company-series` / `industry-funnel` / `bottleneck-hunter` / `earnings-team`，或用户未指定期限** → **默认长期模式**。

> **为什么必须区分（v7.1 复审结论）**：四大师（段永平/巴菲特/芒格/李录）都是**长期所有权投资者**，其核心判据——护城河、长期竞争优势、十年期管理层品质——**信息半衰期以年计**。在 1-12 个月窗口内，这些判据**基本不产生可交易信号**，却会系统性诱导"因为公司好所以继续拿着"的沉没成本推理。两套模式**并行存在、不可混用**：长期模式问"这是不是一门值得持有十年的好生意"，战术模式问"未来 12 个月靠什么赚钱、市场已经定价了多少"。

### 第一步：展示团队框架

向用户展示**对应模式**的团队结构，确认后启动：

#### 长期模式（默认，四大师视角）

| 角色 | 职责 | 分析框架 |
|------|------|----------|
| **team-lead**（你自己） | 统筹协调、汇总研判、输出最终报告 | 四大师综合框架 |
| **business-analyst** | 商业模式 & 护城河分析 | 段永平视角 |
| **financial-analyst** | 财务报表 & 估值分析 | 巴菲特视角 |
| **industry-researcher** | 行业格局 & 竞争态势 | 芒格视角 |
| **risk-assessor** | 风险评估 & 管理层研判 | 李录视角 |

#### 战术模式（1-12 个月，四路期限适配视角）

| 角色 | 职责 | 核心问题（必须回答，答不出=该维度不合格） |
|------|------|----------|
| **team-lead**（你自己） | 统筹 + **四大师闸门**裁定 | 见文末"四大师闸门" |
| **catalyst-path** | 催化剂与事件路径 | **未来 1-12 个月会发生什么？** 事件清单 + 日期锚点 + 概率 + A/B/C/D 分级（C/D 级不建仓）。"若什么都没发生，靠什么涨？" |
| **expectations-gap** | 市场预期差 | **市场当前定价了什么？** 卖方一致预期分布、期权隐含 move vs 基本面预期 move 的 EV 校验、估值分位、拥挤度与筹码。**我的判断与共识的分歧点在哪、为什么市场错了** |
| **fundamentals-1to12m** | 基本面与估值（短口径） | **未来 2-3 个季度的收入/利润率/FCF 路径**（分部拆解）+ 估值分位与可比。**不输出"十年护城河"论述**。若未来两季度不及预期，逻辑是否仍成立 |
| **risk-sizing** | 风险、仓位与流动性 | 下行场景与幅度、σ（用于反解止损宽度）、ADV 与仓位占比、与现有持仓相关性、**论点证伪的可观测指标**（"看到 X 就说明我错了"）、**建议仓位%（半凯利，上限 15%）** |

**战术模式下的四大师闸门**（team-lead 在汇总时逐条裁定，任一不通过 → 否决，不接受"但预期收益很高"的辩解）：

| 大师 | 战术模式下保留的判据 | 否决触发 |
|------|---------------------|---------|
| 段永平 | **能力圈排除器**：能否一句话说清"这笔钱未来 12 个月靠什么赚、赚谁的" | 说不清盈利来源 / 依赖无法验证的叙事 → 否决（"不懂不做"最硬） |
| 巴菲特 | **下行保护**：悲观场景 -X% × 仓位 ≤ 单笔风险预算 1.5% | 超预算且无更窄止损可行 → 否决或强制缩仓 |
| 芒格 | **证伪清单**：主动列举"我可能错的三种方式"；当期治理红旗（大额减持/增发/会计变更） | 找不到任何反面证据（=没认真找）/ 存在治理红旗 → 否决 |
| 李录 | **尾部风险**：地缘、监管、汇率、流动性、资本周期位置 | 存在不可对冲且不可承受的尾部 → 否决或压缩敞口 |

> ⚠️ **闸门是"不做什么"的清单，不是"做什么"的清单**。战术模式下"买什么"永远由催化剂 + 预期差 + 赔率决定；**"这是一家好公司"不构成 1-12 个月的买入理由**。

### 第一步半：AI研究偏见评估

在创建团队前，先向用户展示该公司的"AI可研究性"评估：

**信息丰富度评级**（决定研究策略）：
| 等级 | 特征 | 研究策略调整 |
|------|------|------------|
| A级（信息充裕） | 上市多年、券商覆盖广 | 团队重点放在**反面检验**和**非共识视角**，避免输出与市场一致的"正确的废话" |
| B级（信息适中） | 上市不久、覆盖有限 | 每个Agent的推算数据必须标注置信度，team-lead汇总时标注"数据充分度" |
| C级（信息稀缺） | 冷门/新上市/新兴市场 | 团队转为"第一性原理模式"：不追求报告完整性，聚焦商业本质的几个核心问题 |

**关键提醒**：资料多≠确定性高，资料少≠确定性低。AI能输出的置信度 ≠ 投资的真实确定性。确定性来自商业模式本身，不来自资料数量。

将评级结果告知每个Agent，影响其研究方式。

### 第一步¾：WebSearch 权限预检（关键 · 避免 Agent 静默退化）

在创建团队、启动任何后台 Agent **之前**，必须先确认 WebSearch 权限已放行。

**为什么必须预检**：本 skill 用 `run_in_background: true` 启动 4 个后台子 Agent，而**后台 Agent 无法向用户弹出交互式权限确认**。若 `WebSearch` 未在 `.claude/settings.local.json` 的 `permissions.allow` 白名单中，子 Agent 的联网搜索会被**静默拦截**，导致其退化为仅凭训练知识（有知识截止日期）作答，却仍按框架输出一份"看起来完整、实则未联网"的伪研究——这是本 skill 最危险的失败模式（见 issue #58）。

**预检步骤**：
1. 用 Bash 检查白名单是否含 WebSearch：
   ```bash
   grep -l '"WebSearch"' .claude/settings.local.json ~/.claude/settings.local.json 2>/dev/null
   ```
2. 若两处都未命中（即未放行）→ **停下来，不要启动 Agent**，提示用户：
   > ⚠️ 检测到 WebSearch 未在权限白名单中。后台研究 Agent 无法联网，会退化成仅凭训练知识作答。请先在 `.claude/settings.local.json` 的 `permissions.allow` 加入 `"WebSearch"`（或运行 `/permissions` 勾选），再重跑本命令。
3. 命中 → 正常继续。

### 第一步⅘：四大师本人持仓预检（关键 · 防止"用大师名义背书"）

**在组建团队前，必须先查四位大师本人（或其旗舰机构）对该标的的 13F 持仓方向。**

**为什么必须查（2026-09-11 GOOG 案例）**：本次四路 Agent 全部漏掉了 13F 中的一条关键事实 —— **段永平本人管理的 H&H International Investment 在 2026Q2 减持 Alphabet C 类股约 173.74 万股（−47%）**。而四份报告在引用"段永平视角"时，默认语气是看多。**用一位正在减持的投资人的视角为标的背书，是本框架最荒谬的失败模式。** 根因：任务定义里没有"查大师本人持仓"这一步，Agent 不会主动想到。

**预检步骤**：
1. 用 WebSearch 搜索（美股用 13F，港股/A股用披露易/巨潮权益变动）：
   - `"<TICKER> 13F 2026Q2 Berkshire"` / `"<TICKER> 段永平 H&H International 减持 增持"`
   - 逐项确认：**巴菲特（伯克希尔）／段永平（H&H International）／李录（喜马拉雅资本）** 的最新季度持仓方向（增持/减持/新建/清仓）与幅度。芒格已故，跳过。
2. 把结果写成一条 **"大师本人持仓台账"**，随任务 description 一并下发给四个 Agent，并明确要求：
   > 「引用某位大师视角前，先核对本台账中该大师本人的实际持仓方向。**若大师本人在减持，禁止以该大师名义为该标的背书**，必须如实标注该反证。」
3. 在 team-lead 的四大师闸门裁定表里，**每位大师的裁定都必须有一行"本人持仓方向"作为证据**（长期模式与战术模式均适用；战术模式下这是"证伪清单"的现成素材）。

> ⚠️ **注意**：伯克希尔（巴菲特）与段永平（H&H）在 GOOG 上给出了**相反动作**（伯克希尔 +4,815 万股升至第三大持仓，段永平 −47%）。这种分歧不要调和、不要和稀泥，**如实呈现并说明它反映的核心矛盾**（长持有期看生意质地 vs 短窗口看赔率）。

### 第一步¾-B：并发限流预检（429 防护）

**背景（2026-09-11 GOOG 案例）**：4 个后台 Agent 并发启动触发 **429 频率限制，四个全部阵亡**。报文给出明确的配额重置时间。

**规则**：
1. **重试前必须重新跑 `date` 命令确认当前时间** —— 不要用对话早期读到的时间判断配额是否恢复（本次系统时间与对话内时间戳出现数小时跳变，"立刻重试"的直觉判断是错的）。
2. 若配额未恢复 → **改用一次性自动化在重置时刻之后自动重跑**，不要空等，也不要连发重试浪费配额。
3. 若用户明确要求保持高并发 → 可先发**单发探针**（向 1 个 Agent 发继续指令）验证配额是否活着，探针通过再铺开其余，避免一次烧掉全部配额。
4. **继续（而非新起）被 429 中断的 Agent 更省成本**：它们的任务描述已通过 `TaskCreate` 持久化，用 SendMessage 让它们 `TaskGet` 读回完整规格即可，无需重发长 prompt。

### 第三步：创建4个任务

使用 TaskCreate 创建4个任务（每个都要有 subject、description、activeForm）。

> **⚠️ 战术模式（1-12 个月）下，跳过本节下方的长期模式任务定义，改用「第三步-T：战术模式任务定义」**。长期模式任务问的是"这是不是一门好生意"，在 1-12 个月窗口内会产出大量**不可交易**的结论。

#### 第三步-T：战术模式任务定义（1-12 个月，v7.1 新增）

**四个任务必须问不同的问题**。若四个 Agent 收到的是同一套提示词只换了标题，本次分析**自动无效**（这是最常见的伪并行）。

**任务1：催化剂与事件路径**
- subject: `列出{公司名}未来1-12个月的催化剂与事件路径`
- description 要求：
  1. **事件清单 + 日期锚点**：财报/指引/产品发布/产能/政策/并购/指数纳入/解锁，每条给出**具体日期或日期区间**与**来源链接**
  2. **每条催化剂的 A/B/C/D 分级**：A=高确定性且有明确日期且影响大；B=确定但影响中等或日期模糊；**C/D 级不得作为建仓理由**
  3. **概率估计**：每条催化剂"发生且带来正收益"的概率 p
  4. **必答**：**若所有催化剂都没兑现，这笔投资还靠什么上涨？**（答不出 → 该标的不合格）
  5. ⚠️ **财报前建仓是负 EV**（隐含 move 通常大于预期 move）——默认走 PEAD 路径，即财报后依价格漂移介入。除非做了隐含 vs 预期 move 的 EV 校验并证明为正

**任务2：市场预期差**
- subject: `分析{公司名}的市场共识、隐含预期与分歧点`
- description 要求：
  1. **卖方一致预期分布**（营收/EPS 的高中低、修正方向）、近 90 天修正趋势
  2. **期权隐含 move vs 基本面预期 move 的 EV 校验**：算出关键事件日的隐含波动幅度，与基本面推导的合理幅度比较，给出 EV 正负
  3. **估值分位**（vs 自身 5 年中位、vs 同业）+ 拥挤度/筹码（空头回补空间、机构持仓变化、内部人交易）
  4. **必答**：**我的判断与共识的分歧点具体在哪里？为什么市场错了（或为什么是我错了）？**
  5. **证伪指标**：若市场是对的，会先看到什么数据？

**任务3：基本面与估值（1-12 个月口径）**
- subject: `测算{公司名}未来2-3个季度的经营路径与估值分位`
- description 要求：
  1. **未来 2-3 个季度**的收入/毛利率/经营利润率/FCF 路径，按**分部拆解**（哪块业务驱动）
  2. 近两个季度的实际 vs 预期偏差历史（该公司是习惯性超预期还是不及预期）
  3. 估值：PE/PS/EV-EBITDA 的当前分位与可比公司
  4. **必答**：**若未来两个季度数字不及预期，投资逻辑是否仍成立？**（区分"节奏问题"与"逻辑问题"）
  5. ❌ **禁止输出"十年护城河""长期竞争优势"式论述**——信息半衰期与持有期不匹配

**任务4：风险、仓位与流动性**
- subject: `评估{公司名}的下行场景、止损宽度匹配度与建议仓位`
- description 要求：
  1. **下行场景与幅度**：悲观情景的具体触发路径与 -X%
  2. **波动率 σ**（滚动 90 日年化）→ 用于反解止损宽度：`允许止损宽度 = 1.5% ÷ 仓位%`
  3. **流动性**：ADV（20 日均成交额）是否 >$50M；建议仓位是否 ≤ ADV 的 10%
  4. **与组合现有持仓的相关性**（若调用方提供了持仓清单）
  5. **必答**：**论点证伪的可观测指标**——写清楚"看到 X 就说明我错了"（必须是可观测数据，不是"逻辑变了"这种模糊表述）
  6. **建议仓位 %**：半凯利映射（f*=(bp−q)/b，取一半），硬上限 15%，下限 3%（<3% 机会成本不划算）

#### 长期模式任务定义（四大师视角）

#### 任务1：商业模式分析
- subject: `分析{公司名}商业模式、护城河与用户价值`
- description 包含：
  1. 商业模式本质：核心生意定义、收入结构拆解
  2. 平台/产品飞轮效应如何运转
  3. 护城河分析：品牌/转换成本/网络效应/规模效应/技术壁垒，逐一验证
  4. 用户/客户价值：为各方创造了什么独特价值
  5. 业务矩阵与协同效应
  6. 段永平"好生意"标准评估：差异化、定价权、可持续竞争优势
  7. 要求搜索最新财报、行业报告等公开信息

#### 任务2：财务与估值分析
- subject: `分析{公司名}财务数据、盈利能力与估值`
- description 包含：
  1. 近3-5年营收、净利润、经营利润趋势
  2. 盈利能力指标：ROE、ROA、毛利率、经营利润率
  3. 现金流分析：经营性现金流、自由现金流、资本开支
  4. 资产负债表健康度：现金储备、负债率、流动性
  5. 估值分析：PE/PS/PB/EV等，与历史及同业对比
  6. 安全边际评估：内在价值 vs 当前股价
  7. **⚠️ 成长型公司判定与替代框架**：
     - 先判定：收入增速>50% + CapEx/收入>30% + 未稳定盈利 = 成长型
     - 成长型公司**必须额外评估**：PS vs 同业、PS/增速比、合同积压(RPO/backlog)、毛利率趋势、现金跑道（现金/烧钱率）、客户质量（头部客户是否签约）、Rule of 40（增速+利润率）
     - 成长型公司 FCF 为负不算红旗——但须回答"盈利拐点何时到来？现金跑道够不够烧到那天？"
  8. **金融严谨性验证（必须使用Bash调用工具，禁止心算）**：
     - 市值验算：`python tools/financial_rigor.py verify-market-cap --price {价格} --shares {股本} --reported {报告市值} --currency {币种}`
     - 估值验算：`python tools/financial_rigor.py verify-valuation --price {价格} --eps {EPS} --bvps {每股净资产}`

### 第九步：数据抽检（准出流程）

```bash
# Step 1 — 提取抽检清单（15%随机抽样）
python tools/report_audit.py extract \
  --report <报告文件路径>

# Step 2 — 对清单每项从可靠信源取数（参见 skills/financial-data.md）

# Step 3 — 输出准出/打回判决
python tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report <报告文件名>
```

**【准出】** 全部通过 → 报告可发布；**【打回】** 有不通过 → **必须修正后重跑同一条判决命令复检，直到准出**（2026-09-11 GOOG 案例：首轮打回 2 项，修正后 10/10 准出）。**不要把"打回"直接当成"已完成"交付给用户。**

**内部判断项 vs 可核验项**：抽检清单里会混有评分/概率/情景假设等**内部判断项**（不可外部核验）与财务/持仓等**可核验项**。填 `verdict --results` 时，内部判断项置 `fetched_value: null` 并注明"内部判断项，不可外部核验"（工具会自动跳过），**可核验项必须逐个独立取数，不得填报告自身的值蒙混过关**。

**高频数据陷阱（抽检时优先怀疑这几类）**：
1. **一次性收益污染 EPS → PE 光学陷阱**（GOOG 2026Q2 含 $99B 股权重估收益，16.6x 的 PE 对应真实核心 PE 29.6x）。**看到异常低的 PE，第一件事是查 EPS 里有没有一次性收益。** 让 Agent 同时输出"失真口径"与"归一化口径"两套估值。
2. **源数据内部不自洽 = 坏值信号**（GOOG 的 BVPS 报 $52.37，但同一源自己报的市净率 6.94 对应 $50.90 → $52.37 是坏值）。**当同一数据源的两个字段互相矛盾时，用第三个独立源（Yahoo/Refinitiv）裁决，不要选"看起来更顺手"的那个。**
3. **财报表述口径混淆（盘后 / 次日收盘 / 累计）** —— 必须先问口径再用原始价格序列裁决。
4. **并购重的公司用 PB 无意义**（商誉无形占账面权益 >50% 时换 P/TBV）。
5. **资产负债表时点错配** —— 引用现金/债务前先确认是哪个季度末，融资动作后需重估。

## 重要注意事项

1. **4个Agent必须并行启动**——在同一条消息中调用4次Task工具
2. **Agent通过SendMessage汇报**——不是文件协作，是消息通信
3. **数据准确性**——要求Agent使用WebSearch搜索最新数据，关键数据交叉验证
4. **结论要明确**——不回避给出买入/观望/回避建议和具体价格区间
5. **所有分析必须有数据支撑**——附数据来源
6. **耐心等待**——4个Agent研究需要几分钟，实时向用户更新进度
7. **反偏见意识**——team-lead在汇总时必须评估：各Agent的分析是否受限于资料充裕度？是否与市场共识过度趋同？最终报告需包含"信息丰富度评级"和"AI研究局限性声明"
8. **信息稀缺时的诚实原则**——宁可在报告中留白标注"数据不足"，也不要用推测填满框架伪装确定性
