### 段永平视角 · 商业模式 ★★★☆☆

**一句话：** 在没人愿意做的超罕见病领域做"唯一疗法"供应商——first-in-class基因治疗。

**已上市产品的生意本质：**

| 产品 | 2026指引 | 模式 | 段永平视角 |
|------|---------|------|-----------|
| Crysvita | $5.0-5.2亿 | 美加/欧洲=royalty（Kyowa Kirin主导），拉美/土耳其=直销 | **摇钱树被砍了一半**——已将大量未来royalty出售给OMERS（$5亿换30%美加royalty）和RPI Trust |
| Dojolvi | $1.0-1.1亿 | 直销 | 小而稳定的利基产品 |
| Evkeeza | 增长中 | 直销（新国家上市驱动） | 第三条腿，但市场也极小 |
| Mepsevii | ~$2800万/年 | 直销 | 超罕见病，象征意义大于经济意义 |

**"唯一疗法"模式的数学：**

- GSD1a：全球约6000患者（商业化可及区域更少，估计美国~2000-3000）
- Sanfilippo A（MPS IIIA）：全球约2400患者（MPS III总共~7000，Type A占34%）
- 假设定价$100万-200万/患者（基因治疗典型定价），商业化可及率50-70%：
  - DTX401峰值：$3.0-3.8亿（BioWorld估计）
  - UX111峰值：$1.5-5.0亿（区间极大，取决于加速审批条件）
- **问题：** 即使"垄断"这些超小市场，单个产品天花板$3-5亿。要成为$30亿公司，需要5-7个产品组合。

**"给竞争对手100亿能否复制？"**
- 能复制，但需要5-8年。基因治疗的壁垒不在钱，在：① AAV载体设计Know-how ② 制造工艺CMC（UX111的CRL就是栽在这里）③ 罕见病临床试验网络 ④ FDA监管路径开拓
- 但反过来想：Beam Therapeutics（碱基编辑）、Genethon（法国）也在跟进GSD1a。先发优势有时间窗口，没有专利级的永久护城河。

> **段永平点评：** "这个生意我看得懂——在没人愿意做的小市场做唯一供应商。但小市场的唯一玩家，天花板也矮。Crysvita还把royalty卖了换现金，等于把自己的摇钱树砍了一半。这不是一个能长到很大很大的生意。"

**UX111（Sanfilippo A）竞争格局——零竞争：**

- MPS IIIA全球~2400患者。Sanfilippo是**致命儿童神经退行性疾病**，中位生存~15年
- 当前**无任何获批疗法**
- UX111是**唯一进入BLA审查的基因治疗**
  - Lysogene（被Abeona收购）：早期
  - Denali Therapeutics：酶替代，不同机制，更早期
  - **可预见未来无实质竞争**

## 七、PDUFA批准概率独立估计

### DTX401（GSD1a）—— 65%批准概率

| 利好因素 | 利空因素 |
|---------|---------|
| Phase 3数据扎实（96周cornstarch减少60-64%） | "cornstarch减少"作为endpoint的临床意义可能被质疑 |
| FDA未安排AdCom（积极信号） | FDA对AAV基因治疗安全性整体审查趋严（CTGTAC 7/29讨论） |
| 首个针对GSD1a病因的疗法，巨大未满足需求 | FDA可能要求更长期安全性数据 |
| Priority Review（6个月审评） | 基因治疗BLA的CMC审查通常更严格 |
| GSD1a患者群体虽小但明确（~6000） | — |

**65%的逻辑：** 无AdCom + 数据扎实 + 首个疗法 + Priority Review = FDA认可度较高。降15%是因为基因治疗审批本身的不确定性 + endpoint临床意义可能被质疑。

### UX111（Sanfilippo A）—— 55%批准概率

| 利好因素 | 利空因素 |
|---------|---------|
| 首个Sanfilippo A疗法，零竞争 | **CRL历史**（2025年6月，CMC问题） |
| 加速审批surrogate endpoint（CSF heparan sulfate）被FDA接受 | FDA可能再次挑剔CMC |
| 8年随访数据显示临床改善 vs 自然史对照 | 加速审批被拒概率天然高于常规审批 |
| 重新提交后FDA再次授予Priority Review | 制造一致性是基因治疗行业性瓶颈 |
| Andelyn美国工厂生产（供应链确定性） | Sanfilippo A致命性可能导致FDA更保守（害怕"无效但危险"的治疗） |

**55%的逻辑：** 加速审批 + CRL历史 = 比DTX401更不确定。升5%是因为临床数据确实积极 + FDA重新接受 = 说明CMC问题可能已解决。降至55%是因为加速审批本身的被拒概率更高 + CRL可能复发。
