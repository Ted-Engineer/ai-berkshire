- [x] **关键变量**：① Azure 增速能否守住 35%+；② Copilot 渗透率（当前 ~4.4%）；③ AI capex ROI 兑现；④ OpenAI 关系（2026-04 已改非独家）；⑤ 监管。
- [x] **认知来源**：本会话深度研究（IR 财报 + 多源交叉 + 工具验算），非道听途说。

**评分：★★★★★（5/5）— 通过**
> 模式极其清晰：企业离不开的 IT 基础设施，10 年确定性极高。段永平："这是看得最懂的生意之一——Office 和 Azure，企业搬不走。" 全市场最清晰的能力圈之一。
