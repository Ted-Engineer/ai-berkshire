## 六关审判

### 第一关 · 能力圈：我能理解这门生意吗 ★★★★ → ✅

- **一句话**：向企业收"客户数据操作系统"的年费——销售管道、客服工单、营销数据都在上面跑。
- **10 年后大概率还在做什么**：还在管企业客户数据与流程；但收费单位大概率从"座位"部分转向"Agent 工作量"（AWU）。形态会变，本质不变（观点，基于公司 Agentforce 战略与用量数据）。
- **关键变量**：① 座位数 vs Agent 用量的定价转换率；② 有机增速能否回到 10%+；③ Data Cloud 能否守住数据引力。
- **认知来源**：本次 SEC 一手文件 + 实时财务数据研究，非道听途说。

**评分 ★★★★**：模式清晰、有技术门槛、10 年确定性较高但形态存变。

**评分 ★★★★**：至少一条强护城河（转换成本+数据）且整体稳定，但品类级风险压住第五颗星。

## 关键风险（3-5 条）

1. **8/26 财报证伪"有机再加速"**（概率中、影响大）：Q1 有机约 8.7%（推算），若 Q2 cRPO 增速跌破 10%，估值与论文双杀。
2. **AI 侵蚀座位制**（概率中、影响大）：10-K 自认的品类级风险；Curative $600K 合同流失是样本。慢变量，季度财报难捕捉。
3. **$30B 净债务**（概率低、影响中）：年息约 $1.34B（$25B 债券加权票息 5.36%），压缩未来回购/并购弹性，AI 逆风时放大下行。
4. **管理层交接期执行风险**（概率中、影响中）：COO 上任一周、工程一号位离职，Agentforce 工程靠 7 月底空降的新 EVP 撑。
5. **Informatica $9.6B 整合**（概率中、影响中）：商誉 $5.3B，若 Cloud ARR（现 $1.1B）增长失速将触发减值风险。
