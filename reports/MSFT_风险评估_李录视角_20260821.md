## 五、仓位合理性裁决

### 风险预算校验（精确计算）
```
止损距离 = (481.15 − 436) / 481.15 = 9.38%
组合风险 = 9.8% × 9.38% = 0.92% ≤ 1% ✅ 通过
```

### 裁决：**持有全部60股，让利润奔跑，不兑现**

理由（李录视角）：
1. **基本面在自我证明**：Azure 43%再加速（非减速）、全年营收+17.8%、经营利润+21%——"capex证伪"论点刚被财报打了脸，此时减仓是卖出正在兑现的论点
2. **风险预算合规**：0.92%在1%限额内，纪律框架完整
3. **存档规则未触发**：Azure 43% ≫ 35%阈值，无需减20股；下一判定点为10月底FY27Q1
4. **聪明钱在场**：Ackman建仓并持有、Berkshire疑似买入——与"兑现离场"的机构行为相反

### 触发条件（动词+条件）
