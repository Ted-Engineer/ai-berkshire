## 一、一句话结论

> HIMS的GLP-1业务（占收入40-50%）是**监管套利窗口，不是护城河**——FDA已于2025年初将semaglutide移出shortage list，诺和诺德/礼来诉讼胜势明显，窗口最晚2027年大概率关闭。CEO Andrew Dudum通过10b5-1持续大规模卖出（无买入记录）。Teladoc从$300→$10（跌96%）的历史就在眼前。剥离GLP-1后底盘业务内在价值仅$6-10/股，三情景加权期望~$27≈现价，**无安全边际，不是30%重仓标的**。

## 三、否决的3个核心理由

### 🔴 理由1：GLP-1是监管租金，不是护城河（芒格一票否决）

| 核实项 | 事实 |
|--------|------|
| FDA对semaglutide shortage designation | **2025年初已宣告解除** |
| 503B过渡期 | 最晚2027年大概率关闭 |
| 诺和诺德/礼来诉讼 | 胜势明显，进一步加速清退 |
| HIMS定价优势来源 | $199/月（仿制）vs $1300/月（Ozempic）—— **价差100%来自监管豁免** |
| 护城河判定 | ❌ 监管套利窗口，不是技术/规模/品牌壁垒 |

**Teladoc警示**：Teladoc从$300跌至$10（跌幅96%）——telehealth不是护城河，这是已被市场血泪证明的事实。

### 🔴 理由2：CEO Dudum在持续卖出（李录一票否决）

- 通过10b5-1计划每季度卖出数百万至数千万美元
- **无公开市场买入记录**
- Class V股：以5-8%经济持股掌握35-45%投票权，无日落条款
- SPAC上市（2021年）——历史扣分项
- 与CRDO对比：CRDO创始人11.84%持股($46亿身家在船上)，高位小额卖出<财富1%

**李录格言**："管理层用脚投票比他们说什么更诚实。"

### 🔴 理由3：无安全边际 + 极度不确定估值（巴菲特一票否决）

| 情景 | 前提 | 目标价 | 概率 |
|------|------|:--:|:--:|
| 乐观 | GLP-1豁免维持 | $50-75 | 25% |
| 中性 | GLP-1部分收缩 | $12-27 | 45% |
| 悲观 | FDA完全撤销，GLP-1归零 | $6-10 | **30%** |
| **加权期望** | | **~$27** | |

- 基础业务（剥离GLP-1）内在价值仅$6-10/股
- 当前$25股价中$15-19是GLP-1期权溢价——取决于一场未决联邦诉讼
- 估值区间$6-75，跨度11倍，本身说明业务不符合"确定性"要求
