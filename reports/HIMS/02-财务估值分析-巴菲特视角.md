## 1. 公司概况

Hims & Hers Health（NYSE: HIMS）是一家通过订阅制模式提供远程医疗和处方药服务的平台公司。2021年1月通过SPAC方式上市。

### 业务线构成（估计，FY2024末）

| 业务线 | 营收占比（估计） | 核心产品 | 特征 |
|--------|---------------|---------|------|
| 体重管理（GLP-1） | ~40-50% | 复方司美格鲁肽（Compounded Semaglutide） | 监管风险高，增长最快 |
| 男性健康 | ~30-35% | 非那雄胺（脱发）、西地那非（ED） | 成熟稳定，高毛利 |
| 女性健康 | ~15-20% | 避孕、护肤、甲状腺 | 增长中，毛利高 |
| 其他 | ~5% | 心理健康等 | 早期阶段 |

## 3. 盈利能力分析

### 毛利率结构

| 业务层级 | 毛利率（估计） | 数据基础 |
|---------|-------------|---------|
| 男性/女性健康订阅 | ~78-82% | 类SaaS模式，边际成本极低 |
| GLP-1复方处方 | ~50-60% | 含药物成本、药剂师、合规、冷链 |
| **公司整体** | **~70-75%** | 随GLP-1占比上升，综合毛利率承压 |

**趋势判断**：GLP-1占比持续提升→整体毛利率趋降。若GLP-1消失→整体毛利率反弹至80%+，但营收腰斩。

### 营业利润与盈利轨迹

| 指标 | 状态 | 说明 |
|------|------|------|
| GAAP净利润 | 历史持续亏损，FY2024部分季度接近盈亏平衡 | 营销费用占营收比重高 |
| EBITDA | FY2024部分季度转正（估计） | 依赖GLP-1贡献 |
| 经营现金流（OCF） | FY2024估计转正区间 | 订阅预付款结构有利 |

**盈利质量问题**：HIMS的利润严重依赖GLP-1复方业务这一"监管临时许可"。核心订阅业务（男女健康）单独来看，已接近EBITDA盈利，但规模支撑力不足。

## 5. 三情景估值模型

GLP-1监管结果是HIMS估值的核心变量。以下三情景基于不同监管假设。

### 情景A：乐观——GLP-1豁免维持 + 持续增长

**前提假设**：法院裁定支持HIMS，FDA无法强制终止复方司美格鲁肽销售；或HIMS成功转型"差异化配方"（添加B12/其他）并获得长期豁免。

| 指标 | 数值（估计） |
|------|-----------|
| FY2026E 营收 | $2.5-3.0B |
| EBITDA率 | ~15-18% |
| 合理P/S | 4-5x |
| 对应市值 | $10-15B |
| 对应股价 | **$50-75** |
| 主观概率 | **约25%** |

### 情景B：中性——GLP-1部分收缩，其他业务补位

**前提假设**：FDA部分执行，复方豁免收窄但不完全消灭；HIMS获得部分GLP-1合法处方渠道（如与Novo Nordisk合作）；其他业务加速增长补位。

| 指标 | 数值（估计） |
|------|-----------|
| FY2026E 营收 | $1.2-1.8B（GLP-1贡献下降50-70%） |
| EBITDA | 可能短暂转负，重整期 |
| 合理P/S | 2-3x |
| 对应市值 | $2.4-5.4B |
| 对应股价 | **$12-27** |
| 主观概率 | **约45%** |

### 情景C：悲观——FDA完全撤销豁免，GLP-1归零

**前提假设**：最高法院或联邦巡回法院支持FDA，复方司美格鲁肽全面停售；HIMS失去最大收入来源，被迫大规模裁员和成本重构。

| 指标 | 数值（估计） |
|------|-----------|
| 核心业务营收（男女健康） | ~$800M-$1B |
| EBITDA | 初期转负（固定成本尚未调整） |
| 合理P/S | 1.5-2x（纯亏损订阅业务） |
| 对应市值 | $1.2-2.0B |
| 对应股价 | **$6-10** |
| 主观概率 | **约30%** |

## 6. 巴菲特核心问题

### Q1：若GLP-1监管结果不确定，怎么计算内在价值？

> 巴菲特："内在价值是一家公司存续期内可产生现金的折现值。如果我无法在合理范围内估计这个现金流，我就不会投资。"

**回答：几乎无法可靠计算。**

GLP-1的监管结果是一个离散的法律事件，不是连续的商业风险。两种可能：
- 法院支持 → 现金流路径A（估值$50-75）
- 法院支持FDA → 现金流路径C（估值$6-10）

两条路径相差8-10倍，DCF模型在这种情况下的精度毫无意义。巴菲特从不在无法框定内在价值区间的公司上押注。

**但另一方面**：情景不确定性本身创造了市场错误定价的机会——如果投资者能够独立判断诉讼概率，可能找到不对称回报。但这需要法律专业知识，而非投资能力。

### Q2："基础业务"（剔除GLP-1）值多少钱？

**核心订阅业务独立估值：**

| 指标 | 数值（估计） |
|------|-----------|
| 非GLP-1营收（FY2024估计） | ~$700-800M |
| 毛利率 | ~78-80%（高质量订阅） |
| 成熟期净利润率假设 | ~8-10% |
| 年化净利润（稳态） | ~$56-80M |
| 合理PE倍数（稳定增长订阅业务） | 20-25x |
| 对应市值 | **$1.1-2.0B** |
| 对应股价 | **$5.5-10** |

**结论：基础业务对应股价约$6-10，与情景C完全吻合。**

这意味着GLP-1业务在当前~$25股价中贡献了约**$15-19的溢价**（约60-75%）。这个溢价完全取决于一场法律诉讼。

> 巴菲特："安全边际意味着：即使我对这门生意的所有判断都错了，我也不会亏钱。HIMS的情况恰恰相反。"

### Q3：现价是否有安全边际？

**结论：无安全边际。**

- 若按基础业务（剔除GLP-1）计算内在价值：$6-10
- 估计当前股价：~$25
- 隐含安全边际：**负150-300%**（即股价高于基础价值2.5-4倍）

即使最乐观地假设中性情景成真，对应价格~$12-27，当前价格的安全边际也接近于零甚至为负。

只有乐观情景（概率25%）才能提供正回报，而巴菲特从不依赖乐观情景作为安全边际的基础。

## 7. Teladoc教训：远程医疗的生死线

| 维度 | Teladoc（历史） | HIMS（当前） | 相似度 |
|------|--------------|------------|-------|
| 核心叙事 | 远程医疗将颠覆传统就医 | GLP-1远程处方将颠覆减重市场 | 高度相似 |
| 叙事破灭触发器 | 增长放缓+盈利遥遥无期 | FDA监管打击GLP-1复方业务 | 均为外部冲击 |
| 峰值股价 | ~$300（2021年初） | ~$72（2025年初） | 均在泡沫顶点 |
| 峰值P/S | ~20x | ~8x | HIMS相对便宜 |
| 叙事破灭后 | $8-10（跌97%，用了约3年） | 已从$72跌至~$15-25（跌65-80%） | 进行中 |
| 核心问题 | 高估值+增长叙事破灭 | 高估值+监管叙事二元风险 | 结构相似 |
| 区别 | 盈利问题是慢性病 | 监管风险是急性事件 | HIMS风险更集中 |

**关键差异**：HIMS基础业务（男女健康订阅）比Teladoc更健康、更有定价权。这是HIMS比Teladoc更有投资价值的地方。但这种优势被GLP-1的监管不确定性完全压制。

> 芒格："从Teladoc学到的教训不是'不投远程医疗'，而是'不以增长叙事代替内在价值'。"

## 8. 综合评估与巴菲特视角评分

### 巴菲特核心投资标准逐项评估

| 评估维度 | HIMS表现 | 评分 |
|---------|---------|------|
| 护城河宽度 | 订阅黏性一般，GLP-1无护城河（监管套利） | ★★ |
| 业务可预测性 | 极低——取决于诉讼结果，二元跳变 | ★ |
| 管理层质量 | 创业能力强，但在监管灰色区押重注，风险偏好过高 | ★★ |
| 财务健康度 | 毛利率高但FCF不稳定，稀释严重 | ★★ |
| 估值安全边际 | 基础业务内在价值$6-10，当前约$25——无安全边际 | ★ |
| 生意简单性 | 订阅模式简单，但监管博弈复杂，巴菲特不喜欢 | ★★ |

### 最终评分

**★★（2/5）**

**评分理由：**

1. **核心订阅模式值得认可**：男女健康订阅业务具有高毛利、复购黏性、简单商业模式，这些符合巴菲特偏好。
2. **GLP-1不是护城河，是监管套利**：依赖FDA短缺豁免销售复方药物，豁免一旦取消，竞争优势立即消失。这不是巴菲特所说的"经济护城河"。
3. **内在价值无法可靠计算**：估值结果区间$6-75，取决于法庭判决，而非商业竞争力。
4. **无安全边际**：即使按中性情景，当前价格约等于期望值，没有留出"即使我错了也不亏钱"的空间。
5. **管理层风险偏好不符**：在监管敏感地带大规模押注，而不是建立持久竞争壁垒。

**"现价有无安全边际"最终结论：**

**没有安全边际。**

当前约$25/股的价格包含了大约$15-19的GLP-1期权溢价，这个溢价完全取决于一场未决的联邦诉讼。基础业务（剔除GLP-1）的内在价值约为$6-10/股。从巴菲特的角度，这不是投资，而是在一场法律赌局中下注。

如果用户对HIMS感兴趣，**等价格**是更合理的策略：
- 若诉讼败诉后股价跌至$8-12区间，基础业务本身具有投资价值
- 彼时GLP-1期权溢价已被消化，真正的安全边际才会出现
