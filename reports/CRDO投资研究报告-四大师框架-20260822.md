## 二、投资论点
> Credo 是 AI 数据中心"铜互连"事实标准制定者——自研 SerDes 芯片 + 垂直整合 AEC 电缆，已进入所有主要 hyperscaler BOM。FY2026 收入 3 倍爆发至 $1.34B，FCF margin 从 6.6% 跃至 30.5%，零负债 $1.45B 净现金。收购 DustPhotonics 补全光互连版图，FY2027 指引 >80% 增长。但 92x P/E、P/S 32x 比所有可比公司贵、前 3 客户占 88%、CEO/CFO/COO 三人半年减持 $35M+——好公司不等于好价格。这是"用 95 分价格买 100 分公司"的博弈，安全边际为零。

## 三、四大师综合分析

### 3.1 段永平视角（商业模式）：★★★★☆ — 4.0/5

**核心判断：看得懂的好生意，但"永恒性"存疑**

**✅ 强项（段永平会喜欢的）**：
1. **Fabless 轻资产印钞机**：807 人创造 $42.6B 市值，无工厂无重资产，68% 毛利率 = 定价权铁证。段永平最欣赏的"少花钱多赚钱"模式。
2. **商业模式简单可理解**："AI 数据中心需要更多更快的连接线，Credo 卖芯片+电缆一体方案"——一句话讲清楚。
3. **AEC vs 光模块的精确定位**：铜互连（机架内 ≤2m）vs 光互连（机架间 >2m）不是替代关系而是互补。Broadcom 管理层公开背书铜直连路线至少到 2028 年。DustPhotonics 收购让 Credo 两条腿走路。
4. **Design Win 壁垒 = 转换成本**：AEC 进入 hyperscaler AI 集群 BOM 后，可靠性验证周期 12-18 个月，换供应商成本极高。这是"进去就出不来"的生意。
5. **收入是重复性出货**：不是一次性项目制，每个 AI 集群持续需要连接，量随 GPU 部署线性增长。

**⚠️ 减分项（段永平会犹豫的）**：
1. **客户集中度致命**：前 3 客户占 88%——本质是"给 3-4 家超大客户供货的零件商"，任何一个转向自研就是收入塌方。
2. **速度型护城河非结构型**：Broadcom/Marvell 不需要 $10B 就能复制 SerDes 技术。Credo 的优势是"先发+垂直整合+已卡位"，需要每 1-2 年用新一代产品重新赢。段永平更喜欢"10 年不用管"的生意。
3. **技术路线存续性**：铜互连在 3.2T 时代是否仍成立？如果光进铜退加速到机架内，AEC 的 TAM 会被压缩。

**段永平式一句话**："这门生意我看得懂，也确实是好生意，但它不是茅台——它更像给苹果供应链做连接器的立讯精密，好但命运在客户手里。这个价格，我宁可等一等。"

**评分：4.0/5**

### 3.3 芒格视角（行业与竞争）：★★★★☆ — 4.0/5

**核心判断：AI 连接是真正的结构性趋势，Credo 卡位精准，但竞争格局非独占**

**✅ 行业结构性利好（芒格会认可的）**：
1. **TAM 爆发式扩张**：AI 连接 TAM 从 $10B → $154B（Goldman），Credo 自身估算 >$10B（18 个月翻 3 倍）。这不是周期性泡沫，而是物理定律驱动——GPU 越快，数据搬运瓶颈越大。
2. **1.6T 升级周期才刚开始**：800G → 1.6T → 3.2T，每代升级连接数量翻倍。PCIe Gen6 采样 = 下一代设计锁定中。这是"物理定律站在你这边"的行业。
3. **AEC 品类的开创者优势**：Credo 实质上创造了 AEC 这个品类（HiWire 品牌），市占率领先。2026 年预计 1000 万条 AEC 出货。
4. **DustPhotonics = 端到端平台**：收购后覆盖"铜（AEC）+ 光（silicon photonics）+ IP（SerDes/DSP）"，成为唯一的全栈 AI 互连纯玩家。
5. **vs 竞争对手的定位**：
   - Broadcom/Marvell：巨头，但 AI 连接只是其业务一小部分，不会为 AEC 投入专注度
   - Astera Labs (ALAB)：只做芯片不做电缆，无垂直整合
   - Credo：唯一"芯片+电缆+光"一体的纯 AI 互连公司

**⚠️ 芒格会警惕的**：
1. **SemiAnalysis 判断**："Marvell 和 Broadcom 将最大受益，Credo 将失去市场份额"——巨头一旦认真进入，小公司的份额会被侵蚀。
2. **Hyperscaler 自研悬顶之剑**：如果 Amazon/Google 决定自研 retimer/AEC，Credo 的 88% 客户集中度就是致命弱点。
3. **单 bit 成本年降 33% 的结构性通缩**：连接行业的"量增价减"是永恒主题，量能否持续跑赢价？
4. **AI capex 周期性**：所有 hyperscaler 同时扩产 → 同时消化 → 同时暂停。2027-2028 存在 capex 暂停风险。

**芒格式一句话**："这是一个真正的好行业——物理定律驱动需求、技术升级周期明确、品类正在被创造。Credo 的卡位比 Astera 好（垂直整合），比 Broadcom/Marvell 专注（纯玩家）。但我讨厌 88% 客户集中度和'速度型护城河'——这不是 See's Candies，这是需要每年重新赢一次的比赛。"

**评分：4.0/5**
