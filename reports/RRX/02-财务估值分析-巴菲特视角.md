## 二、人形机器人业务估值

### 2.1 当前规模

根据摩根大通分析师Tomohiko Sano的研究：

| 指标 | 金额 | 占总收入比 |
|------|------|-----------|
| 已签约人形机器人年收入 | >$30M | 0.51% |
| 总机会管线（人形+协作+手术机器人） | ~$200M | 3.4%（潜在） |
| FY2025总收入 | $5,935M | 100% |

**来源**：Finviz/JPMorgan研究报告

### 2.2 $200M管线折现分析

RRX在人形机器人领域的定位是"卖铲人"（picks-and-shovels）模式——不造整机，而是提供电机、驱动器和运动控制系统。这个定位有利有弊：

**正面**：不依赖任何单一机器人厂商的成功，受益面广
**反面**：不掌控终端产品，定价权有限，技术壁垒不如核心零部件（如谐波减速器、力矩传感器）高

折现计算（保守假设）：

| 假设 | 参数 |
|------|------|
| 管线转化率 | 50%（5年内） |
| 转化后年收入 | $100M |
| EBITDA利润率 | 20%（运动控制零部件典型水平） |
| EBITDA贡献 | $20M/年 |
| 估值倍数 | 10x EBITDA |
| 总估值 | $200M |
| 每股价值 | ~$3.00 |
| 占当前股价($185)比例 | 1.6% |

**结论**：即使$200M管线全部转化，对人形机器人的估值贡献仅约每股$3。$185股价中人形机器人的合理价值占比不应超过2%。

### 2.3 但另一方面（反面论据）

- 摩根大通全球人形机器人出货量在2025年已达约13,000台，中国厂商占近80%，成本年降40%
- 巴克莱预测人形机器人市场到2035年可达$2000亿
- 如果RRX能从0.5%的市占率提升到2-3%，管线可能远超$200M
- RRX的组件已进入主要手术机器人平台，这条赛道的增长确定性更高

**但这些是2028-2030年以后的事**。对当前估值的支撑微乎其微。

## 六、核心风险

### 6.1 资产负债表风险（最高优先级）

| 指标 | RRX | 健康标准 |
|------|-----|---------|
| 总债务 | $4.86B | — |
| 净债务 | $4.46B | — |
| 利息覆盖(FY24) | 1.6x | >3x |
| 净债务/FCF | 5.0x | <3x |
| D/E比率 | 0.70 | <0.5 |
| 债务/EBITDA | ~3.7x | <2.5x |

利息覆盖仅1.6x意味着经营利润的63%用于支付利息。如果经济衰退导致经营利润下降30%，利息覆盖将降至1.1x——接近危险区域。FY2024利息费用$399.7M吞噬了经营利润$642.5M的62%。

### 6.2 GAAP vs 调整后盈利的持续性差距

- 无形资产摊销FY2024为$511.8M（D&A总额），其中大部分来自并购产生的无形资产
- 这意味着公司过去的并购溢价正在通过会计利润的减少来"偿还"
- 重组费用反复出现（FY2022: $46.8M, FY2023: $148.4M+减值），说明运营整合远未完成

### 6.3 管理层变动

Q1 2026财报中宣布Aamir Paul将接任CEO。管理层过渡期增加不确定性。

### 6.4 人形机器人落空风险

- 摩根大通自己也承认"人形机器人有意义的收入仍需数年"（JPM AM报告原文）
- Interact Analysis预测全球人形机器人收入到2035年才$150亿——RRX能分到多少高度不确定
- 即使$200M管线全部转化，对$5.9B收入的公司来说只是3.4%

### 6.5 但另一方面（正面因素）

- FCF确实强劲，公司正在积极去杠杆（FY2025偿还了$700M+债务）
- 订单增长强劲（Q2日常订单+8.8%），backlog持续上升
- 数据中心需求推动增长（Q4 2025特别提到数据中心订单加速）
- 航空航天和离散自动化需求也在增强
- 管理层有明确的40%+毛利率目标路径

### 最终判断

1. **RRX不是巴菲特会买的生意**。高杠杆（利息覆盖1.6x）是巴菲特的一票否决项。巴菲特对高负债公司的态度是：*"如果你看到一家公司有大量债务，就跳过它。"*

2. **自由现金流是真实的亮点**。$893M的FCF、15%的FCF利润率、7.3%的FCF收益率——这些数字比许多科技公司还好。但高杠杆使得这些现金流必须优先用于还债，而非回报股东。

3. **人形机器人是真实的但定价过度**。$30M已签约收入和$200M管线确实存在，但占总收入比例不到0.5%和3.4%。股价三个月67%的涨幅主要由这一叙事驱动，Q2财报后14%的暴跌是市场对过度乐观的修正。

4. **当前$185仍无安全边际**。DCF内在价值约$127，巴菲特买价区间$95-130。需要再跌30-50%才进入考虑范围。

5. **反面论据**：如果你相信人形机器人是下一个AI级别的产业革命，且RRX的"卖铲人"定位能捕获比$200M管线大得多的机会，那么当前的FCF收益率和前瞻P/E（17.5x）在工业股中不算昂贵。但这属于风险投资逻辑，而非价值投资逻辑。
