## 0. 一页结论

**Oracle是"两半公司"：一半是全世界最好的软件收租生意（数据库+维护费），一半是全世界最烧钱的资本赌局（OCI + Stargate）。**

- **数据库那半**：接近无敌的护城河，20-30年客户锁定，每年收22%维护费，毛利率90%级——这是段永平说的"好生意"。
- **云那半**：Q4基础设施收入+93%增长惊人，但背后是FY2026年$557亿资本开支、$1670亿总债务、S&P降至BBB-（仅高于垃圾级一档）、自由现金流为负。这是"需要不断借钱维持的增长"。
- **段永平式判断**：数据库部分是"数字世界的收租人"；但公司整体变成了"借债建厂的基建商"。好生意+坏价格之外的第三种问题：**好生意正在被改造成重资产生意**。
- **为什么跌66%**：不是数据库基本面恶化（云数据库收入仍+29%），而是市场对"资本开支无底洞 + 债务膨胀 + OpenAI单一客户依赖 + 循环资金链"的重新定价。这是基本面结构变化，不是纯情绪。
- **综合评分：★★★☆（按本团队评分规范取整 ★★★★）**——数据库★★★☆☆级护城河，OCI把公司整体拉到四星。

## 1. 先纠三个偏（数据准确性优先）

### 1.1 "90%企业市场份额"不成立

任务背景称"Oracle数据库90%企业市场份额"。这是营销口径，不是市场份额。可查数据：

| 口径 | 数据 | 来源 |
|---|---|---|
| 企业数据库市场收入份额 | Oracle ~18.4%（2025），微软14.6%第二 | dataintelo |
| 关系型数据库客户数占比 | Oracle DB 9.49%（37,325个客户）；MySQL 39.5%、PostgreSQL 18.6%领先 | 6sense / r-oracle社区估计 |
| 广泛流传的"90%财富500强使用Oracle" | 属公司营销话术，未获独立审计验证 | 公司宣传 |

**结论**：Oracle是全球企业数据库收入第一（约18-28%区间，不同机构口径差异大），且单位客户价值极高（银行/电信/政府核心系统），但绝不是"90%份额"。护城河分析不需要虚增数字——**1个摩根大通的核心账务系统客户，价值大于1万个免费MySQL用户**，这才是垄断的本质。

## 2. 商业模式本质：Oracle到底在卖什么？

### 2.1 三块生意

**① 数据库（Database）—— 现金牛（轻资产收租）**
Oracle Database + 自治库 + 中间件 + 云数据库（Autonomous DB on OCI）。Q4云数据库收入+29%。企业核心交易系统（银行账户、电信计费、政府档案）的地基。收入模式：许可费（一次性）+ 每年约22%维护费（永久性）。**这是"卖保险柜+每年收管理费"的生意。**

**② 应用软件（SaaS/ERP）—— 增长引擎（轻资产订阅）**
NetSuite、Fusion ERP/HCM、供应链等。全球企业应用第二极（SAP之后）。Q4 SaaS收入约$4.1B。订阅制，毛利率80%+。

**③ OCI云基础设施（IaaS）—— 资本黑洞/增长火箭（重资产）**
2021年起All-in AI算力。Q4 IaaS收入$5.8B（**+93%**），主要来自AI训练/推理（OpenAI等）。需要每年数百亿capex买GPU建数据中心。**这是"盖电厂"的生意——先花钱，后收电费。**

### 2.2 FY2026收入结构（截至2026-05-31，来源：Oracle IR财报）

| 项目 | FY2026 | 同比 | 说明 |
|---|---|---|---|
| 总收入 | $67.4B | +17% | 创纪录 |
| 其中：云收入（IaaS+SaaS） | $34.0B | +39% | 占比~50% |
| —— Q4云基础设施IaaS | $5.8B | +93% | 近翻倍 |
| —— Q4云应用SaaS | ~$4.1B | 低双位数 | |
| 其余（传统许可+支持+硬件+服务） | ~$33.4B | 低个位数 | 传统现金牛 |
| GAAP EPS | $5.83 | +34% | |
| Non-GAAP EPS | $7.63 | +27% | |
| 资本开支 | $55.7B | +162% | 占收入83% |
| 经营现金流 | ~$23.7B | | 自由现金流≈-$32B（负） |
| RPO（剩余履约义务） | $638B | +363% | 详见第3节 |

**结构性判断**：收入的"质"在变——轻资产软件占比下降、重资产IaaS占比上升。FY2026每$1收入对应$0.83资本开支；FY2027指引capex $900-950亿 vs 收入目标$900亿——**每$1收入对应$1+资本开支**。Oracle正从"软件公司"变成"AI基建公司+软件公司"。

## 3. $638B RPO backlog 是什么概念？

### 3.1 定义与量级

RPO（Remaining Performance Obligations）= 已签合同、尚未确认的收入——**"已签未交付"**。$638B ≈ 9.5倍FY2026年收入、10倍"年收入"（Reddit财经讨论口径）。

一年前（FY2025 Q4）RPO只有$138B，一年增长+363%（$500B增量）——**增量几乎全部来自AI大单，其中最大单笔是OpenAI的$3000亿/5年合同（2027年起，4.5GW算力）**。这是人类商业史上最大的单个客户合同之一。

### 3.2 质量细节（好坏两面）

| 事实 | 数据 | 来源 |
|---|---|---|
| 已预付或客户自带硬件部分 | $75B（约12%） | 财报会转述（LinkedIn/TheStreet） |
| 2027财年（FY2027）内转化为收入的占比 | 仅12%（~$77B） | 财报会转述 |
| 与FY2027收入目标$90B的关系 | 已有合同覆盖~85%的目标 | 推算（$77B/$90B） |
| 其余大部分 | 2028-2031年确认 | 财报结构 |

**正面解读（可见性实锤）**：FY2027的$90B收入目标（+34%）中约85%由已签合同背书。企业历史上极少有公司拥有这种收入可见性。如果全部兑现，2028财年后收入将冲击$120-150B。

**反面解读（三大质量疑点）**：
1. **收入≠利润**：交付$638B需要先花掉$900-950亿/年的capex（FY2027指引）。合同越多，欠的基建越多。这是"先垫资后收租"，且垫资速度超过了收租速度（FCF为负）。
2. **单一客户集中**：OpenAI占RPO增量的主要部分。OpenAI自身仍在亏损、依赖新一轮$4000亿估值融资。循环资金链（SoftBank→OpenAI→Oracle→Nvidia/电力）只要一环松动，$638B就会缩水。
3. **合同可重谈**：2025年5月OpenAI-微软-Oracle-SoftBank-Nvidia"五点协议"表明大客户算力合同是动态博弈的结果。OpenAI是否对Oracle承担take-or-pay义务——**未披露，无法验证**。

**段永平式提问**：$638B是"未来的现金流"还是"未来的资本开支义务"？两者都是。真正的问题是：**交付这些合同之后，还剩多少自由现金流？** 目前答案是为负。

## 4. 护城河分析（段永平框架：独特的生意=别人抢不走的生意）

| # | 维度 | 评级 | 证据（正） | 证据（反） |
|---|---|---|---|---|
| 1 | 数据库转换成本 | ✅ | 企业核心数据库迁移需5-10年、数亿美元风险（账务/计费/政府系统）；Fortune 500深度绑定数十年 | PostgreSQL等开源替代在增量市场侵蚀；新应用可绕过Oracle选云原生库（Aurora/Postgres） |
| 2 | 客户锁定（支持收入） | ✅ | 22%年维护费制、客户已支付巨量沉没成本；云数据库收入Q4仍+29%（Futurum） | 云迁移中部分客户把维护费转为云费，客户总成本不降 |
| 3 | 定价权（数据库） | ✅ | 历史上Oracle对许可/支持维持年涨约4-8%的惯例（公开报道惯例，未逐一验证） | 云时代企业IT预算谈判更强势；纯DB新许可量增长放缓 |
| 4 | OCI AI云地位 | ⚠️ | Q4 IaaS $5.8B（+93%），增速远超三大云；公司称GPU利用率97.5%（公司口径，财报会发言） | 全球份额仅~1.3-3%（第4-7名），AWS 30-32%/Azure 20-22%/GCP 12-14%（CRN/Synergy多口径）；无平台网络效应，靠产能+价格+独家合同抢单 |
| 5 | Stargate项目角色 | ⚠️ | 名义三巨头之一（OpenAI+Oracle+SoftBank，$500B/10GW）；Abilene首个集群2025-09上线（CNBC） | 微软仍是OpenAI最大算力供应方（五点协议）；2026-03 Oracle与OpenAI砍掉Abilene 600MW扩建（Enverus/DCK）——扩张缩水是真实信号 |
| 6 | RPO合同墙 | ⚠️ | $638B历史之最，覆盖FY27目标85% | 集中度+循环资金+合同可重谈（见3.2） |

**护城河综合评级：**
- **数据库/应用软件：★★★★★**——全球只有Oracle能把"卖数据库+收维护费"做成百年生意。转换成本是软件行业最深的护城河形态。
- **OCI AI云：★★☆**——没有品牌忠诚、没有切换成本、没有网络效应；客户（OpenAI们）是逐GPU而居的游牧民族。Oracle凭"先建产能+低价"留客。
- **公司整体：★★★★**——数据库的护城河足够深，足以让公司在AI赌局失败时"活着回来"；但也正是这条护城河让市场愿意给Oracle借钱（BBB-仍可融$400亿），使其有能力继续赌。

## 5. 定价权：数据库能涨价，云不能

### 5.1 数据库定价权：✅ 有

- 历史上Oracle对数据库许可和支持服务维持每年提价约4-8%的惯例（行业公开报道的长期惯例，本次研究未逐一验证单年幅度）。
- 维护费按许可费的~22%/年收取，客户续费是自动的、不可谈判的（不续费=失去升级与安全补丁，对企业是致命风险）。
- 反方：纯本地许可新销售增长已停滞（传统软件收入低个位数增长），定价权更多体现在"存量提价"而非"增量扩张"。

### 5.2 云定价权：❌ 基本没有

- AWS/Azure/GCP/Neocloud多强并立，GPU算力是标准化商品，客户按美元/GPU/小时比价。
- Oracle的差异化是"性能+价格"（公司长期宣传"2倍性能、半价"）和"GPU现货可得性"（2023-2025年芯片荒时Oracle能更快交付）——**这两者都不是定价权，而是产能权**。
- 反证：连OpenAI这种超级客户都只在"五点协议"谈判桌上给微软、Oracle分蛋糕，且2026年3月缩水600MW扩建——超级买家随时会重新议价。

### 5.3 为什么Oracle毛利率80%+，却缺钱？

| 指标 | 数据 | 解读 |
|---|---|---|
| 总毛利率 | ~80%（公司口径，FY2026） | 软件许可边际成本趋零+维护费高利润+OCI利用率提升（公司称GPU利用率97.5%） |
| 营业利润率 | 被折旧/利息持续压缩 | FY2027收入+34%但EPS指引仅+18%（Seeking Alpha）——**增长的钱大部分被折旧和利息吃掉** |
| 自由现金流 | FY2026约-$32B（OCF $23.7B - capex $55.7B） | 毛利率再高，也扛不住每年$560-950亿资本开支 |
| 融资 | FY2026已融资$430亿债+$50亿股；FY2027再融资$400亿 | 增长靠借债+增发维持 |

**一句话**：Oracle的毛利率高是因为"软件"部分毛利率极高；但公司的钱不是被毛利率烧掉的，是被**资本开支**烧掉的。毛利率80%和缺钱可以同时成立——这正是"重资产化"的证据。

## 7. 为什么股价跌66%？——基本面恶化还是情绪？

**答案：两者都有，但主体是基本面结构变化（重定价），不是纯情绪。**

### 7.1 真·基本面恶化（被证实的）

1. **信用降级**：S&P 2026-07-10将Oracle从BBB降至BBB-（BBB-/A-3，理由是业务风险上升+现金流走弱），债券收益率升至6.1-7.8%（Bondsupermart）。
2. **债务膨胀**：总债务2026-05峰值$167.4B（Finbox），长期债务$122.3B（+43% YoY，Macrotrends），净债务~$97.6B。
3. **自由现金流为负**：FY2026约-$32B；S&P警告现金消耗可能达$42B/年（Briefs）。
4. **EPS增长跑输收入**：FY2027收入+34% vs EPS+18%——折旧与利息开始吃掉股东回报。
5. **云收入微miss**：Q4云收入$9.91B vs 预期$9.97B（Yahoo）——在高估值时期，微miss也致命。

### 7.2 情绪/叙事层面（部分被证伪）

- "OpenAI循环资金链"担忧：SoftBank→OpenAI→Oracle→Nvidia，资金在产业链内循环的质疑（CNBC多篇报道）。
- "AI泡沫"叙事降温：市场从"买AI任何环节"转向"要求盈利和现金流"。
- 反方：$638B合同是真实签署的（WSJ/CNBC），五角大楼$70亿合同（2026-07-23）证明实体需求仍在增加。

### 7.3 结论

数据库业务本身没有坏消息（云数据库+29%、五角大楼续约、RPO中的传统合同部分仍增长）。**市场抛弃的是"资本开支无底洞+资产负债表恶化+单一客户依赖"的组合**。$120的价格不是"好公司错杀"，而是市场对"重资产化Oracle"的重新定价。是否错杀，取决于一个无人能回答的问题：**AI算力需求在2027-2030年兑现多少？**
