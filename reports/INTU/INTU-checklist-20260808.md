## 三、六关 Checklist

### 第一关：我能理解这门生意吗（能力圈）— ★★★★☆

**一句话赚钱方式**：向美国个人收报税软件与专家服务费（TurboTax）、向小微企业收订阅费（QuickBooks），并用积累的财务数据把用户导流给金融机构收撮合佣金（Credit Karma）。

三条腿的经济性完全不同，必须分开理解：

| 业务 | 收入模式 | 9MFY26 增速 | 10 年后还在吗 |
|------|---------|------------|--------------|
| QuickBooks/GBS | SaaS 订阅 + 支付/工资单抽成 | +17.1% | **大概率在**。小微企业记账是法定需求，转换成本极高 |
| TurboTax | 季节性一次性付费 + Live 专家 | +7.5% | **形态存疑**。报税需求必在，但"入口"可能变 |
| Credit Karma | 免费信用分引流 → 贷款/保险撮合佣金 | +21.5% | 在，但强周期（利率敏感） |

**关键变量**：① TurboTax 单量与 ARPU（提价能否持续）；② QBO 净新增与提价承受力；③ Credit Karma 撮合量（利率周期）；④ 通用 AI Agent 是否绕过软件入口。

**认知来源**：本次读了 Q3FY26 10-Q 全文（295K 字符）、5/20 财报新闻稿、195 份 Form 4、法律进展原文，非道听途说。

**为何不给五星**：报税与记账的**需求**确定性接近五星，但 **交付入口**在 AI 时代的形态有真实不确定性。段永平说"看不懂就别买"——这里不是看不懂生意，是**看不清 3 年后的入口形态**，扣一星。

### 第二关：这是一门好生意吗（经济特征）— ★★★★★

工具验算输出（`verify-valuation`，精确十进制）：
```
PE (TTM):  325.25 / 16.43 = 19.80x     盈利收益率: 5.05%
PB:        325.25 / 75.21 = 4.32x      ROE: 21.85%
P/FCF:     325.25 / 27.8  = 11.70x     FCF Yield: 8.55%
股息率:    4.8 / 325.25   = 1.48%
```

| 指标 | INTU 数值 | 参考标准 | 判断 |
|------|----------|---------|------|
| ROE | **22.5%**（TTM），5年区间 18.9-22.5% | >15%优秀，>20%卓越 | ✅ 卓越 |
| ROIC | **20.6%** vs WACC 约9% | 显著超越资本成本 | ✅ 真实创造价值 |
| 毛利率 | **80.8%** | >40% 暗示定价权 | ✅ 远超 |
| 自由现金流 | TTM **$7,755M**，为净利的 **1.69x** | 持续为正、≈净利 | ✅ 优于净利 |
| 资本开支强度 | **占收入 0.6%** | 轻资产优于重资产 | ✅ 极轻 |
| 有息负债/净利润 | $6.90B / $4.58B = **1.5 年**；净债务≈0 | <3 年 | ✅ 达标 |

**六项全部达标 → ★★★★★。**

FCF 是净利的 1.69 倍，原因是 SBC（$2,039M 非现金）+ 递延收入（订阅预收）+ 极低 CapEx。这是软件生意的教科书特征。

**反面论据（必须列）**：
1. **SBC 占收入 9.7%** 是真实的股东成本。扣 SBC 后 FCF $5,716M，收益率降到 **6.30%**。这是"好生意"里最贵的一项隐性支出。
2. **GAAP 经营利润率 27.5%，不是简报说的 47%**。80.8% 毛利率与 27.5% 经营利润率之间的 53pct 差距，全部消耗在销售营销（TurboTax 每年税季的巨额广告投放）与研发上。这门生意的高毛利需要持续高营销投入维持，不是茅台式的自然垄断。
3. 商誉 $13.98B 占总资产 36%，是 Credit Karma（$71亿）+ Mailchimp（$120亿）两笔并购的产物。**历史零减值**（已核实 FY19-FY25 GoodwillImpairmentLoss 全部为 0），但这也意味着一旦 Mailchimp 继续走弱，减值风险是账面上的悬顶之剑。

> 芒格："如果生意做得好，股票最终会跟上。" 从纯经济特征看，这确实是一门顶级生意——但要用 GAAP 27.5% 而不是季节性 47% 来认识它。

**给对手 100 亿能否复制？**
不能。100 亿能买到工程师和广告位，买不到：① 数十年的报税数据与审计辩护案例库；② IRS 与 50 个州税务机关的认证通道与对接工程；③ 会计师渠道生态（ProTax/Lacerte 的执业习惯）；④ 为报税结果承担法律与赔付责任的资产负债表与保险安排。

**但必须给出反面论据——AI 可能让"复制"变得不必要**：
护城河防的是"正面攻城"，AI 的威胁是**绕行**。若用户直接对通用 Agent 说"帮我报税"，护城河被绕过而非攻破。这是本关不给五星的唯一原因，也是全篇最重要的风险。

#### 【关键争议核实】IRS Direct File 2026 状态 —— 尾部风险已消除

任务简报称这是"最大尾部风险"。**一手核实结果：Direct File 已终止，风险已经出清，且结果对 INTU 有利。**

三个独立信号交叉确认：

| 信号 | 结果 |
|------|------|
| ① IRS 官网 Direct File 页面 | **HTTP 404**（页面已下线） |
| ② IRS Free File 官方页面（2026-06-12 最后更新） | 只列 Guided Tax Software（AGI ≤$89,000）与 Free File Fillable Forms 两个选项，**全页零次提及 Direct File** |
| ③ 公开记录汇总 | 2025-11-06 IRS 停止该免费直报服务；程序标注"2024 创立，2026 终止"；One Big Beautiful Bill Act 最终文本未强制取消，改为要求 IRS 组建公私合营替代方案工作组 + $1,500 万研究经费 |

**含义**：市场担心的"政府免费报税吃掉 TurboTax"这一尾部风险，**在 2025 年 11 月就已实质解除**。ITEP 曾估算 Direct File 可为纳税人年省约 $110 亿的费用与时间成本——这笔钱现在继续留在商业报税软件的市场里。

**反面论据（三条，必须给）**：
1. **治理瑕疵**：公开记录显示 Intuit 与 H&R Block 花费数百万美元游说终止该项目。**靠游说而非产品优势维持的护城河，质量低于靠产品维持的护城河**，且可为未来政治风向反转埋下伏笔（法案要求的"公私合营替代方案"工作组仍在，2028 年后可能以另一形式回来）。
2. Direct File 使用率本就极低（对照：现有 Free File 仅 3% 合格纳税人使用），因此它的终止对 TurboTax 的**增量**利好可能小于市场叙事。
3. 它的终止不能防御**商业性 AI 竞品**——真正的威胁从来不是 IRS，而是通用 LLM。
