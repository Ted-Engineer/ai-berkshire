## 三、六关 Checklist 逐关评分

### 第一关：我能理解这门生意吗（能力圈）— ★★★★

**一句话赚钱方式**：向美国个人收报税软件与专家服务费（TurboTax）、向小微企业收财务与工资订阅费（QuickBooks）、并用积累的信用与消费数据把用户导流给金融机构收撮合佣金（Credit Karma）。

**关键变量**：① TurboTax 单量与 ARPU（提价能否持续）；② QuickBooks 净新增与提价承受力；③ Credit Karma 撮合量（利率周期）；④ 通用 AI Agent 是否绕过软件入口。

**10 年后还在做什么**：报税与记账是法定刚需，**需求必在**；但"交付入口"存在真实不确定性——用户可能从"用 TurboTax 软件"迁移到"让通用 Agent 帮我报税"。

**认知来源**：本次交叉引用了 20260808 版对 Q3FY26 10-Q 全文、5/20 财报、195 份 Form 4、法律进展原文的一手研读，非道听途说。

- **正面论据**：商业模式一句话能说清，无复杂金融杠杆，收入模式（订阅+交易佣金）透明；三大业务均是"数字管道"生意，10 年需求确定性高。
- **反面论据**：对巴菲特的能力圈标准而言，软件订阅属可理解但需一定专业背景（SaaS 指标、递延收入、SBC）；更关键的是**交付形态 3 年内可能被 AI 改写**——"看得懂生意，看不清入口"。

> 段永平："买股票就是买公司。"——INTU 的"公司"不难懂，难的是 3 年后的报税入口长什么样。看懂 7 成，扣一星。

> 芒格："如果生意做得好，股票最终会跟上。"从经济特征看这是顶级生意——但要用全年 27.5% 而不是税季 47% 来认识它。

### 第三关：护城河够不够深（竞争优势）— ★★★★★

| 护城河类型 | 具备? | 具体证据 | 变宽/变窄 |
|-----------|:----:|---------|----------|
| 品牌/定价权 | ✅ 强 | TurboTax 单量增长有限但收入 +7.5%，靠 **ARPU 提价**驱动；QuickBooks Online Ecosystem +22%（剔 Mailchimp） | 宽，但提价正是 AI 竞品攻击面 |
| 转换成本 | ✅ 极强 | QuickBooks 承载工资、报税、支付、对账全链路；换软件 = 换整套财务历史 + 换会计师 | 宽 |
| 网络效应 | ⚠️ 弱 | 仅 Credit Karma 有双边撮合（用户↔金融机构）；核心产品无网络效应 | 中性 |
| 成本/规模优势 | ✅ | 1 亿+客户摊薄 43 个州税法合规成本与 AI 研发投入 | 宽 |
| 技术/数据壁垒 | ✅ | 数十年报税与小微财务数据积累（数据包称 **60PB**，未能独立核实，标"估计"）；IRS 认证 e-file 通道（资质壁垒） | 稳定 |
| 监管/资质壁垒 | ✅ | IRS Authorized e-file Provider + 50 州税务机关对接 + 为报税结果承担法律责任与赔付的能力 | **因 Direct File 终止而变宽** |

**给竞争对手 100 亿美元能否复制？**
不能。100 亿能买到工程师与广告位，买不到：① 数十年的报税数据与审计辩护案例库；② IRS 与 50 州税务机关的认证通道与对接工程；③ 会计师渠道生态（ProTax/Lacerte 执业习惯）；④ 为报税结果承担法律与赔付责任的资产负债表与保险安排。

- **正面论据**：TurboTax 在 DIY 报税市场近垄断地位，QuickBooks 在小微记账近乎标配，双垄断叠加监管资质壁垒，属于软件业最深护城河之一；Direct File 终止让"政府免费替代"这条最大尾部风险在 2025-11 已实质出清。
- **反面论据（必须列）**：
  1. **AI 威胁是"绕行"而非"攻破"**——若用户直接对通用 Agent 说"帮我报税"，护城河被绕过而非击穿。这是不给五星外的唯一保留项，也是全篇最重要风险；
  2. 靠游说而非产品优势维持的护城河质量更低（公开记录显示 Intuit 与 H&R Block 曾斥资数百万美元游说终止 Direct File），且 2028 年后公私合营替代方案工作组仍可能以另一形式回归；
  3. 直接受益有限——被终止的 Direct File 使用率本就不高（对照：现有 Free File 仅约 3% 合格纳税人使用），增量利好或小于市场叙事。

> 芒格："反过来想，总是反过来想。"护城河防的是正面攻城；AI 的威胁是绕行。深，但并非无懈可击——这正是"打 7 折买 A+ 资产"与"便宜买陷阱"的分水岭。

- **正面论据**：Goodarzi 内部培养、6 年稳定运营，营收翻倍、利润率扩张、大额回购缩股，运营层面是合格乃至优秀的经营者；2026 年有内部人（董事）真金白银买入；暴跌后暂停抛售计划可解读为缓和信号。
