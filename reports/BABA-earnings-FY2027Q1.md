## 二、本期最重要的3个变化

**1. 云业务加速实锤，且第一次给出了"质量"证据。** 外部收入增速40%→45%（与7月初预告一致），EBITA +133%、利润率12%，AI产品收入12.4B连续12季三位数增长。这是本季唯一全面超框架过线的指标——云不再是"增长故事"，开始交出利润表证据。

**2. CMR失速是最大负面意外。** CMR -7%（剔除新商家发展计划的contra revenue后LFL仅+1%），而上季LFL还有+8%。管理层归因"交易活动疲弱"——**这是宏观/消费层面的归因，不是口径问题**。即时零售带来的MAU增量未能对冲take rate/交易量下滑，电商基本盘的定价权担忧被坐实。

**3. 现金消耗进入新量级：FCF -44.7B + 回购停摆。** Capex单季67.7B（环比+152%）把FCF砸到史上最差，现金储备跌破5,000亿，季度回购仅$162M（象征性）。管理层用"disciplined and sustained investments"描述全栈AI投入，但本季没有任何capex上限或FCF转正时点的量化指引。**资本配置重心已从股东回报完全转向AI军备竞赛。**

## 四、附注与隐藏信息挖掘

### 4.1 异常信号检测

- [x] **有效税率异常**：所得税12,798M / 税前利润22,308M = **57.4%**（去年同期17.6%，上季约32%）。减值与罚款大概率不可抵扣+预提税，但仍属罕见水平，直接吞掉约9B净利。低置信度归因，待电话会确认。
- [x] **预付应收环比+17.8% > 营收环比+10.5%**：大概率是芯片/服务器采购预付款（与capex激增一致），非渠道塞货，但需连续两季观察。
- [x] **商誉减值4,458M**（"其他"分部业务）：连续两季减值（上季也有大额），说明历史收购资产的账面价值仍在出清。
- [x] **欧盟DSA罚款€550M拨备**（计入G&A，G&A率3.0%→4.7%）：针对AliExpress，国际业务合规成本上升，且AliExpress刚实现经营盈利就被罚款侵蚀。
- [x] **回购几近停摆**：$162M/季 vs 此前日度$50-100M——这是资本配置转向最直接的证据，比任何管理层表态都诚实。
- [x] **非流动投资-1,069亿**：部分重分类至流动（补充流动性弹药），部分为公允价值变动；投资处置收益减少导致"利息与投资收入"-48%，这是GAAP净利-75%的重要推手之一（非经营性）。
- [ ] 应收账款增速>收入增速：未单独披露应收，预付/应收合并口径下未见渠道塞货证据
- [ ] 存货积压：直营业务主动收缩（-10%），无积压信号

### 4.2 口径变化警示（重要）

本季起分部重组为四块（电商集团/AI云与计算/AI实验室与应用/其他），历史序列已重述。**旧口径的"云智能集团"与"中国电商集团"不再可直接对比**；即时零售从独立披露变为并入电商集团——想跟踪其亏损收窄曲线，只能依赖电话会的口头数字。这是本季报告质量的隐性降级。

## 七、结论：这份财报改变了什么？

1. **超预期/符合/低于预期？** —— **结构性分化，整体"收入符合偏好、利润低于预期"**。营收略超LSEG（268,953 vs 268,880M）、云=预告值（45%）；但Non-GAAP EPS $1.26显著低于一致预期$1.77，FCF创最差纪录。不能用"基本符合"含糊——**这是一份用利润表现换增长叙事的财报**。
2. **对投资论文的影响：削弱（非破裂）**。云+AI一条腿明显变强，FCF一条腿明显变弱；电商基本盘（CMR LFL +1%）的失速是新增的结构性担忧。论文从"估值修复"被动切换为"AI转型期权"，而期权的代价（现金消耗）比买入时预期的更高。
3. **下一个催化剂**：① 今日电话会纪要（即时零售亏损定量、capex指引、回购态度）；② FY27Q2财报（11月，验证云能否维持45%+、CMR能否回到+5%）；③ Qwen3.8-Max商业化数据；④ 1260H/NS-CMIC地缘事件（清仓级风险仍在）。
4. **持仓操作（按预置纪律）**：**减仓至≤5%（减持约128股）**。若用户基于AI转型叙事选择覆盖机械结论，最高容忍线为：FY27Q2若FCF亏损仍>-150亿或CMR LFL继续<+3%，则无条件执行减仓，不再复议。
