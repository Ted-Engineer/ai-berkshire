## 四大师视角分析

### 一、段永平视角：商业模式与好生意标准 — ★★★☆☆（3/5）

**商业模式本质**：双引擎。QCT（芯片，TTM营收占比约77%）卖Snapdragon/Dragonwing平台，赚产品利润；QTL（专利授权，占比约13%）按手机售价抽成，EBT margin 72%，是真正的"收费站"。两引擎互为犄角：芯片份额维持专利话语权，专利现金流补贴芯片研发（9M FY26研发$7,523M，占营收22.9%）。

**好生意标准逐项检验**：
| 标准 | 检验结果 |
|------|---------|
| 差异化 | 高端Android旗舰SoC近乎独占（事实：FY25 QCT non-Apple营收+18%来自premium ASP提升），但中低端被联发科持续侵蚀（观点：竞争方向不利） |
| 定价权 | **正在接受压力测试**：内存/封装成本上涨，公司被迫宣布提价传导（7/29财报原文）——提价能力存在，但客户接受度和份额代价未验证 |
| 可持续竞争优势 | 专利组合（5G/6G）10年维度大概率仍在；handset socket份额10年维度**确定下滑**（Apple自研modem渗透+中国OEM自研，10-Q风险因素原文） |
| 生意是否简单可懂 | 可懂，但技术迭代快，10年终局形态（数据中心能否成第二曲线）看不清 |

**段永平会说**："这家公司在做对的事情（多元化），但主业正在变得不对——当你最重要的客户（Apple）变成竞争对手，这不是周期问题，是结构问题。右侧业务（汽车/数据中心）增长很快但还太小，左侧在漏水。等它证明新引擎能接力，或者价格足够便宜到漏水也无所谓。"

### 二、巴菲特视角：财务与估值 — ★★★☆☆（3/5）

**财务质量（强）**：ROE TTM 33.75%、ROIC 25.6%、毛利率54%、FCF margin 23.6%、流动比率2.02、利息覆盖14.8x。轻资产fabless模式，capex仅占营收4.5%。股东回报凶猛：TTM回购$104亿+分红$38亿≈市值的8%，股本年缩3.65%。**这是巴菲特会喜欢的"用回购把蛋糕切厚"的做法。**

**但盈利在下行**：FY26营收-3.1%、Non-GAAP EPS -12.4%（共识）；Q4指引中值隐含营收同比约-10%（对比FY25 Q4的$11,271M）。巴菲特原则："我宁可要一家暂时遇到困难的优秀公司，也不要一家暂时优秀的平庸公司"——但这里困难不是暂时的（Apple流失是多年过程），优秀程度也在打折。

**现价$167.12 vs 中性$177：上行空间仅+6%，而悲观下行-35.7%。赔率结构不友好。** FCF收益率5.9%+股息2.2%提供约8%的"持有底"，但缺乏价格折扣。

**巴菲特会说**："以合理价格买优秀公司，胜过以便宜价格买平庸公司。问题是：现在的价格'合理'吗？中性情景只给你6%的上行——我要的是四毛买一块，不是平价交易。"

### 三、芒格视角：行业格局与失败模式 — ★★★☆☆（3/5）

**行业现实（ invert, always invert ）**：
1. **内存超级周期正在重塑产业链**：AI抢占DRAM/NAND产能→手机OEM采购受限、整机BOM成本上升（QCOM财报称"input costs broad-based increase"）→QCOM短期量价双承压，但提价若成功则中期毛利受益。这是双刃剑。
2. **客户垂直整合是不可逆趋势**：Apple自研modem（10-Q原文："expect that Apple will increasingly use its own modem...significant negative impact"）；中国OEM在政府半导体自足政策下自研芯片（10-K原文）；Samsung有Exynos。QCOM的handset TAM在结构性收缩。
3. **QTL专利墙仍是全行业最深的护城河之一**：任何卖5G手机的厂商都绕不开（事实：FY25 QTL margin 72%）。但Huawei版税FY25 Q2起归零（事实），且专利费率长期面临监管和谈判压力。
4. **新战场强敌环伺**：数据中心AI芯片对抗NVIDIA/AMD/Broadcom/Marvell；汽车对抗NVIDIA Thor/Mobileye；QCOM优势在低功耗+连接性+性价比，但这是"在别人主场抢份额"。

**失败模式清单**（什么会杀死这家公司）：①Apple+中国流失速度>新业务增长（最可能）；②数据中心投资变成无底洞（Alphawave $2.4B+Modular约$3B已投出）；③内存成本传导失败致毛利坍塌；④中美脱钩升级（中国收入占比高）。

**芒格会说**："这公司有真实的护城河（专利），也有真实的老鼠洞（客户自研）。管理层的应对是把船开向汽车和数据中心——方向对，但新海域里全是鲨鱼。给我看看两年后non-handset收入的真实数字，再谈。"

### 四、李录视角：风险、管理层与文明趋势 — ★★★☆☆（3/5）

**管理层**：CEO Cristiano Amon（2021年起）执行记录可查：FY25 QCT创纪录营收、汽车连续23季双位数增长、多元化目标两次上调（2024-11目标$22B → 2026-06投资者日上调至FY29 $40B non-handset）。资本配置纪律良好：收购规模克制（Alphawave $2.4B现金、Modular 17.83M股≈$3B），回购在低位执行（FY25回购$99亿，期间股价低位）。**瑕疵**：内部人持股仅0.08%（事实，stockanalysis）——管理层与股东的皮肤不够厚；近期多笔Form 4高管减持（事实，SEC EDGAR 2026-07/08多次Form 4/144记录）。

**文明级趋势判断**：边缘AI/物理AI（汽车智能座舱→自动驾驶、机器人、边缘计算）是十年级别真实趋势，QCOM的低功耗计算+无线连接卡位正确（观点）；hyperscaler定制芯片（"a leading hyperscaler custom silicon engagement is on track for initial shipments later this calendar year"——Q2 FY26财报原文，事实）若兑现，是商业模式的质变信号。但AI算力的文明级主战场在数据中心训练侧，那是NVIDIA的领地。

**风险排序**：①Apple/中国客户流失（结构性，高）；②内存周期与成本传导（周期性，中高）；③数据中心执行（战略性，中）；④地缘政治（尾部，中）；⑤QTL专利费率谈判（慢性，中低）。

## 投资论点 Bull vs Bear

**🟢 看多逻辑**：
1. **多元化正在兑现而非画饼**：FY26 non-handset营收+24%，FY27指引>60%；汽车连续23季双位数增长（Q3 $1,588M +61%），FY29目标$40B较2024年翻倍（财报原文）。
2. **估值不贵**：FY26E Non-GAAP PE 15.9x、P/FCF 16.9x，低于自身历史中枢，也低于半导体同业均值；EV/EBITDA 15x。
3. **股东回报确定**：TTM回购+分红$142亿≈市值8%，$20B新授权在手，股本年缩3.65%——即使EPS原地踏步，每股价值也在增厚。
4. **数据中心从0到1**：hyperscaler定制芯片CY26H2首批出货（Q2财报原文）；Alphawave（SerDes IP）+Modular（AI软件）补齐技术栈；AI推理对低功耗芯片的需求真实。
5. **内存提价若成功=毛利期权**：公司已宣布提价，若传导顺利，FY27毛利率有反转弹性。

**🔴 看空逻辑**：
1. **主业在萎缩且看不到底**：Q3 handset $5,086M **同比-20%**，营收连续3季负增长，FY26全年营收-EPS双降；Q4指引偏弱。
2. **Apple流失是结构性的**：10-Q原文确认Apple将越来越多用自研modem，"significant negative impact"；Reuters报道Apple营收下滑已在侵蚀利润预期。
3. **中国双重挤压**：中国OEM自研芯片+政府自足政策（10-K原文）；Huawei版税已归零；地缘政治尾部风险高。
4. **内存成本传导存疑**：提价可能牺牲份额；存货环比+28%至$8,379M，若需求走弱将变减值风险。
5. **赔率不佳**：中性情景上行+6% vs 悲观下行-35.7%；FY26/FY27分析师盈利预期仍在上调后下修，共识$10.54可能还没见底。
