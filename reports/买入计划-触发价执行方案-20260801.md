|------|------|
| 现价（8/1）| ~$192 |
| **买入区间** | **$130-150**（15x FY27 P/S）|

| 验证点 | 9/2 FY27 Q1财报：①光学三线起步（合计>$6亿）②毛利率守67% ③全年指引+80%确认 |

**建仓阶梯**：
```
$150 → 5%   （首批，财报前试探）

合计 → 20%（财报验证后最高30%）
```

**卖出/减仓信号**：毛利率<67% / 全年指引下调 / 大客户（34%）份额异动

## 三、执行纪律

1. **现金管理**：保留$29.5K现金（18.5%）——触发价出现前不动用
2. **挂单**：CRDO $150（5%）、LEU $130（5%）——条件单自动触发
3. **监控**：跨会话定时任务（8/5 LEU、8/7 NBIS、9/2 CRDO）自动检查触发
4. **仓位上限**：单只≤30%、两只合计≤50%（触发价全达标时）
5. **止损纪律**：任何标的跌破止损位无条件执行
