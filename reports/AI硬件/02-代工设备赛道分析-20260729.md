## 二、段永平视角：生意本质

### TSMC — 芯片制造的"终极收费站"

段永平说"买股票就是买公司，买公司就是买其未来现金流的折现"。TSMC的生意本质异常清晰：**任何想造先进芯片的公司，都得给台积电交"过路费"**。

- **定价权**：毛利率从Q1的66.2%提升到Q2的67.7%，在资本开支高达$620亿的背景下仍在提升——说明定价权极强。N3/N2节点客户排队等产能，台积电不是求客户下单，是分配产能。
- **商业模式特征**：高固定成本+超高转换成本。一座3nm工厂造价$200亿+，不是开玩笑的竞争门槛。客户一旦把设计绑在台积电制程上，换厂成本极高。
- **CoWoS——第二个收费站**：Nvidia包下60%的CoWoS产能（约59.5万片晶圆/年），从35K wpm（2024末）扩到130K wpm（2026末），仍然供不应求。这不是普通封装，是AI芯片的**必需品**，台积电收了制造费还要收封装费。段永平会爱这个生意。

**★评分：5/5**（生意本质顶级——双重收费站模式，无可替代）

但注意段永平的另一面：他买苹果是因为"用户离不开"，台积电的客户（苹果/Nvidia/AMD）离不离得开？答案是：短期离不开，长期有风险。

### ASML — 人类技术垄断的天花板

- **100%垄断**：EUV光刻机全球只有ASML能造。不是"主要供应商"，是"唯一供应商"。一台High-NA EUV卖$3.8-4亿，供不应求。
- **定价权证据**：FY2026收入指引从€360-400亿上调到€430-450亿，毛利率54-56%。一台机器$4亿，客户（TSMC/Samsung/Intel）排队等交付。这不是"客户关系"问题，是"客户求着你"的关系。
- **生意的美**：每一代先进制程（7nm→5nm→3nm→2nm→1.4nm）都需要更精密的光刻，ASML的机器是必需品，且用量增加——N2需要的EUV光刻层数比N3多，意味着单厂ASML设备采购额增长。

**★评分：5/5**（全球唯一，不可复制，每一代制程都用更多ASML设备）

段永平的"收费站"理论用在ASML上比TSMC更纯粹——TSMC还有三星/Intel追，ASML没有竞争者。

### AMAT — 好生意但不是垄断生意

- AMAT是全球最大晶圆制造设备商，核心在沉积（PVD/CVD）和刻蚀。但**不是唯一**，Lam Research是直接对手，东京电子(TEL)也在竞争。
- 沉积市场份额从2007年的48%降到2018年的38%——不是增长趋势，是被蚕食。
- 毛利率~48%，营业利润率~35%，放在一般行业算顶级，但跟TSMC（68%GM/60%OM）和ASML（55%GM）比，差了一个档次。
- CEO Gary Dickerson说"这是半导体历史上最伟大的时代"——但AMAT受益的是**量**，不是**定价权**。设备采购的决策权在TSMC/Intel/Samsung手里，AMAT是供应商，不是收费站。

**★评分：3/5**（好行业里的好公司，但不是垄断型企业）

## 三、巴菲特视角：财务与估值

### TSMC — PE 29x vs "地缘折扣"叙事

**核心数据**：

| 指标 | 数值 |
|------|------|
| TTM EPS | $13.86 |
| TTM PE | ~28.8x |
| 远期PE（2026E） | ~23.8x |
| ROE（估） | ~30%+ |
| 收入增速（YoY） | 36%（Q2） |
| CapEx 2026 | $620亿 |
| FCF（估） | 受CapEx压制，但FCF/收入仍在改善 |

**一个被忽视的事实：TSMC的PE已经不是20x了。**

市场流行的"TSMC因台湾地缘风险享受PE折价（20x vs 全球半导体~25x）"叙事已经过时。TSMC当前TTM PE约29x，远期PE约24x——**这个"地缘折价"已大幅收窄，甚至消失**。

- Morningstar公允价值$428/ADR，对应26x 2026E盈利。当前$399距此还有7%空间，但安全边际不大。
- Needham目标价$530（远期~31x），更激进。
- 如果用巴菲特的标准：ROE持续>30%，轻资产（相对），增长>30%，29x PE不算离谱。但巴菲特买股票喜欢"雪茄烟蒂"价格——PE 12-15x才是他的舒适区。29x对巴菲特而言不便宜。

**判断：PE从20x涨到29x，地缘折价叙事已经部分被市场消化。当前价位不是"便宜"，是"合理偏高"。**

**★评分：3/5**（生意顶级，但估值已不便宜。格雷厄姆不会在这个价位买）

### ASML — PE 55x TTM / 36x Forward，贵吗？

| 指标 | 数值 |
|------|------|
| TTM PE | ~55x |
| 远期PE | ~36-40x |
| 收入增速 | ~35-40%（FY2026指引上调幅度） |
| PEG（5年预期） | ~2.2x |
| ROE | ~50%+ |

- 55x TTM PE看起来贵，但要注意ASML的EUV交货周期长，利润确认有滞后。远期PE 36x更反映真实盈利能力。
- 问题在于：36x PE对应的增长率是~35-40%，PEG约1x——这在半导体设备里不算特别便宜。
- ASML护城河确实深到"不可能被颠覆"，但市场已经充分定价这种垄断。$1,757的股价意味着市场假设EUV垄断在未来10年都不会被挑战。

**巴菲特的视角**：他喜欢"以合理的价格买伟大的公司"。ASML符合"伟大公司"定义，但55x TTM PE绝对不是"合理的价格"。36x远期PE勉强在合理上限。如果巴菲特要买，他可能在等待一个20-30%的回调。

**★评分：3/5**（垄断独一无二，但价格已经把未来3-5年的好光景都折现了）

### AMAT — PE 53x，但刚暴跌了28%

| 指标 | 数值 |
|------|------|
| TTM PE | ~53x |
| 股价（6月30日） | $723 |
| 股价（7月27日） | $517 |
| 月度跌幅 | -28.5% |
| FCF Q2 | $8.45亿（运营现金流） |
| 股东回报Q2 | $7.65亿（回购+分红） |

- AMAT股价从6月30日$723暴跌到7月27日$517——一个月跌掉了近30%。即使在PE~53x的高位，这种幅度的下跌说明市场对其周期性高度敏感。
- Q1 FCF为$10.4亿，Q2运营现金流$8.45亿（包含$4亿回购+$3.65亿分红）——几乎把运营现金流全部分配给股东。这是一个高股东回报的公司，但在CapEx高涨期这样做是否合理？
- PE 53x对应的是收入增速仅11%（Q2 YoY）——增速与估值明显不匹配。即使考虑了AI带动的20%+设备增长指引，PEG仍远高于1x。
- CEO在$700+大量减持（$5,550万），不是什么好信号。

**★评分：2/5**（好公司、好行业，但估值与增速的错配最严重，且管理层高位套现）

## 四、芒格视角：护城河深度与"反过来想"

### TSMC护城河：不是3nm，是"整个生态系统"

芒格会说："给我看激励，我就告诉你结果。"

TSMC的护城河不是单一技术，而是：

1. **制造复杂性壁垒**：3nm良率比三星高10-15个百分点。N2良率65-70%（目标75%），Intel 18A只有50-55%。差距不在理论，在一万个小决策的累积。
2. **客户锁定**：苹果/Nvidia/AMD的设计绑定在TSMC制程上。换厂=重做物理设计+重验证+重调良率，1-2年时间窗口。
3. **规模经济**：TSMC收入是三星代工的10倍以上，可以投入更多CapEx。2026年CapEx $620亿，三星代工资本开支不到其1/5。
4. **生态效应**：EDA工具（Cadence/Synopsys）+ IP供应商 + 设计服务公司，全部优先适配TSMC制程。这是鸡和蛋的问题——客户因为生态选台积电，生态因为客户规模而优化台积电。

**反过来想——TSMC最大风险是地缘还是技术替代？**

芒格说："反过来想，总是反过来想。"

- **技术替代风险（低）**：Intel 18A良率50-55%，三星SF2还没证明自己。未来3-5年，技术替代不是实质威胁。但10年维度——如果Intel/三星缩小差距到5%以内，TSMC的定价权会受损。
- **地缘风险（中）**：这是真正的不确定因素。台湾海峡紧张局势——虽然TSMC在亚利桑那投了$2,650亿建12座厂，但最先进的制程（N3/N2/A16）仍然在台湾。如果最坏情况发生，全球芯片供应链断裂。
- **地缘风险的悖论**：正是因为TSMC太重要了，中美都有动机不让它出事。这不是说风险不存在，而是说"所有人都有动力维护它的稳定"。
- **客户自研风险（低-中）**：苹果/Nvidia/AMD未来可能自建设计→制造一体化的能力吗？不可能。Intel的前车之鉴——设计+制造捆在一起反而拖累了竞争力。

**真正最大的风险**：不是地缘，不是技术替代，而是**需求侧假设**。当前TSMC 72%代工份额+30%+增速的假设，建立在"AI资本开支无限增长"的前提下。如果AI投资回报证伪，整个估值逻辑需要重写。

**★TSMC护城河评分：5/5**（5年内不可撼动）

### ASML护城河：30年积累，不可能被复制

ASML的护城河不是一个机器，是整个供应链体系：
- Carl Zeiss的光学镜片（独供，20年合作关系）
- Cymer/ASML自研的EUV光源
- 30年技术积累+数千项专利
- 每一台机器有10万+零件，来自全球供应链

芒格会指出："如果复制一个ASML需要30年和$1,000亿+，那这个护城河就是真的。"

**反过来想——ASML最大的风险是什么？**

- **风险1：中国自主光刻**。中国在用DUV+多重曝光模仿EUV效果，但性能和成本都远不如EUV。5-10年内威胁不大，但20年尺度不确定。
- **风险2：需求周期性**。ASML的客户只有5-6家（TSMC/Samsung/Intel/SK Hynix/Micron）。半导体是周期的，如果AI泡沫破裂，EUV订单可能腰斩。
- **风险3：技术替代**。纳米压印（Canon）、电子束直写等替代技术——目前都不成熟，但"没人能挑战"是危险的假设。
- **风险4：地缘政治**。荷兰政府在美国压力下限制对华出口，ASML处在中美科技战的夹缝中。中国市场占其收入约20%（主要是DUV），一旦进一步收紧，这20%会消失。

**★ASML护城河评分：5/5**（10年内不可能被复制）

### AMAT护城河：宽而不深

AMAT在沉积+刻蚀领域是最大玩家，但不是唯一玩家。Lam Research在刻蚀领域很强（某些细分超过AMAT），东京电子在涂胶显影领域领先。

芒格会说："AMAT的护城河是客户关系+产品广度——但没有'非买你不可'的理由。"

**★AMAT护城河评分：3/5**（可替代性高于TSMC和ASML）

## 五、李录视角：管理层与10年确定性

### TSMC — C.C. Wei

- C.C. Wei 2026年入选TIME100全球最具影响力人物。
- 在张忠谋退休后，他带领TSMC实现了从手机时代到AI时代的成功转型，HPC收入占比从2023年的~40%上升到2026Q2的66%。
- 管理层的关键证明：①$2,650亿美国投资（地缘多元化） ②$620亿CapEx（仍然聚焦长期增长而非短期利润最大化） ③台湾员工分红涨30%+（留才）
- **李录的"10年确定性"问题**：10年后先进制程还在台积电手上吗？回答：以当前技术差距（良率差10-15%）和生态锁定效应，10年内被反超的概率很低。但台积电最先进的节点会逐步分散到美国/日本/德国，台湾本土的集中度会下降——这不一定是坏事，分散化降低了尾部地缘风险。

**★管理层评分：5/5**（C.C. Wei是张忠谋之后台积电最合适的领导人）

### ASML — Christophe Fouquet

- Fouquet 2024年4月接替Peter Wennink（Wennink任内ASML股价涨了1300%）。
- Fouquet是ASML老将（2008年加入），从产品管理到EUV业务，再到CEO，对技术和客户都极其熟悉。
- ASML管理层的特点是：**低调、工程导向、长期主义**。他们用15年开发EUV，现在用同样的耐心开发High-NA EUV和Hyper-NA。
- **10年确定性**：EUV光刻在10年内不会被替代——制程演进roadmap（2nm→1.4nm→1nm）仍然依赖ASML。而且每一代制程需要更多的光刻步骤，ASML设备用量会继续增长。

**★管理层评分：4/5**（工程文化深厚，但还需验证Fouquet的独立领导力）

### AMAT — Gary Dickerson

- Dickerson自2013年起任CEO，在任12年，是半导体设备行业任职最长的CEO之一。
- 他宣称"这是半导体历史上最伟大的时代"——这句话可能是事实，但在$700+大规模减持个人股票（$5,550万）的同时喊"greatest time ever"，信号矛盾。
- AMAT的核心问题是：**它在AI硬件价值链上处于"卖铲子的铲子"位置**——离最终需求（AI应用）太远。TSMC直接卖芯片给Nvidia，ASML卖光刻机给TSMC，AMAT卖设备给所有人——受益但没有定价权。
- **10年确定性**：AMAT的沉积/刻蚀设备10年内仍然重要，但竞争对手Lam Research和TEL不会消失，而且半导体设备的周期性意味着AMAT在某一年可能突然下滑20-30%。

**★管理层评分：3/5**（经验丰富，但高位套现+过于乐观的公开表态值得警惕）

## 六、综合判断

### 关键问题①：TSM PE 29x + 地缘折价 = 机会还是陷阱？

**结论：不是陷阱，但不是便宜货。**

"PE 20x地缘折价"的叙事已经失效。市场在过去12个月重新定价了TSMC：PE从20x涨到29x，市值$2万亿。一部分是因为AI增长确定性被认可，一部分是因为亚利桑那扩张降低了尾部地缘风险。

当前$399的价位：
- 远期PE 24x：不能说贵，因为对应30%+收入增速和68%毛利率。
- 但也不能说便宜：如果AI需求增速从30%降到15%，PE可能压缩到20x以下。
- Morningstar FV $428，向上空间仅7%。安全边际不足。

"段永平会不会在这个价位买？"——如果他相信AI增长可以持续3-5年，24x远期PE是可以接受的。但如果AI需求在2027年放缓，他会后悔。

### 关键问题②：ASML EUV垄断但市场已定价

**结论：已充分定价，需要回调才值得买。**

ASML是地球上最纯粹的技术垄断——100%EUV市场、无可替代。但55x TTM PE和36x远期PE已经把垄断折现得很充分。

如果ASML回调到$1,300-1,400（对应远期PE 27-30x），那是一个更好的买点。当前$1,757的价格假设"一切顺利"——没有中国风险、没有周期下行、没有技术替代。

### 关键问题③：CoWoS瓶颈——TSM的"第二个收费站"

**结论：CoWoS是TSMC最被低估的资产。**

CoWoS从35K wpm（2024末）→130K wpm（2026末）→200K+ wpm（2027）的扩产路线，意味着TSMC不仅卖晶圆，还卖"AI芯片成品"。这是一个高附加值捆绑——客户不仅要给TSMC付制造费，还要付封装费。Nvidia预订了60%的CoWoS产能，说明这个"收费站"的定价权同样极强。

**市场可能低估了CoWoS对TSMC利润率的长尾贡献**。

### TSM当前价位是否值得买入？

**判断：适合建立初始仓位（1/3目标仓位），不适合重仓。**

理由：
1. 远期PE 24x + 30%增速 + 68%毛利 = PEG <1x，估值有支撑

3. 亚利桑那$2,650亿投资降低了地缘尾部风险

**买入策略：$390-400建仓1/3，$340-360加仓1/3，$300以下加最后1/3。**
