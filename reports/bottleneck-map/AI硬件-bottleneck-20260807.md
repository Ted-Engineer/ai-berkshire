## 第二步：供应链物理拆解

```
Layer 0（终端）：AI模型训练/推理服务
Layer 1（核心组件）：GPU/加速器(NVDA/AMD)、HBM内存(MU/SK/三星)、服务器(Dell/SMCI)
Layer 2（重点扫描区）：
  ├─ 网络互联：光模块(中际旭创/COHR)、交换芯片(Broadcom/MRVL)、铜缆
  ├─ 先进封装：CoWoS(TSMC)、ABF基板(Ibiden/Shinko)、HBM TSV
  ├─ 散热/冷却：液冷系统(VRT/nVent/Trane)、CDU、浸没式冷却液 ← VRT所在
  ├─ 电力连接：母线槽、UPS、配电柜(VRT/Eaton/Schneider)
  ├─ 定制ASIC：Broadcom(#1)、Marvell(#2) ← MRVL所在
  └─ PCB/载板：高频高速PCB、IC载板
Layer 3（上游设备/原料）：
  ├─ 刻蚀设备(LRCX/TEL/AMAT) ← LRCX所在
  ├─ 光刻设备(ASML)
  ├─ 量测设备(KLA/CAMT/ONTO)
  ├─ 外延设备(MOCVD/MBE)
  └─ 原材料：高纯金属、特气、靶材
Layer 4（基础设施）：电力(核电/天然气)、冷却水、数据中心土地
```

**VRT一句话**：坐在A级瓶颈上，但P/E 66-80x把所有alpha定价殆尽。nVent是更便宜的替代标的。

- [x] 替代技术风险：**最大风险——最大客户可自研**。Google TPU、AWS Trainium/Inferentia、Meta MTIA都在自研AI芯片。当客户自研成熟，MRVL的ASIC设计服务价值被内部化
- [ ] 稀释风险：数据不足
- [ ] 地缘风险：依赖TSMC（台湾），受地缘影响
- [x] **管理层风险：MRVL历史上是出了名的"underperformer"**——多次收购整合失败（Inphi、Innovium），经常miss guidance，管理层执行力是长期担忧
- [x] 客户集中风险：5大hyperscaler决定ASIC收入

- 当前市值~$182B，10年后25x退出需净利$7.28B
- 当前净利估算~$1B → 需要增长7.3x = 22% CAGR
- 可能但激进——MRVL从未证明能持续高增长
- P/E从40x压缩到25x = -37.5% = 年化-4.5%逆风
- 即使EPS年增22%：22% - 4.5% = **年化约17.5%**——前提是MRVL真能做到22% CAGR
- **结论：⚠️ 如果增速兑现，有安全边际。但MRVL的历史执行力让人质疑22%持续增长的可信度。**

**MRVL vs AVGO（Broadcom）关键对比**：
- AVGO定制ASIC积压订单$730亿（来源：AI五层蛋糕产业研究）；MRVL的积压量远小于此
- AVGO P/S 15-18x，MRVL P/S 26-30x——MRVL更贵但体量更小、地位更弱
- AVGO是ASIC之王，MRVL是#2，且面临客户自研的替代风险
- **结论：如果要投定制ASIC赛道，AVGO是比MRVL更好的标的**

**MRVL一句话**：坐在S级瓶颈上但不是瓶颈的主导者。Broadcom是真正的ASIC之王，MRVL是配角——而配角拿到了比主角更高的估值溢价。

**估值安全边际检验（10年25x PE退出法）**：
- 当前市值~$383B，10年后25x退出需净利$15.3B

- **结论：⚠️ 边缘。不算透支但也无深幅安全边际。理想买入区$220-$260（对应25-30x前瞻PE）。**

### 5.2 反向验证（芒格式否定）

**VRT——聪明人为什么不买？**
- P/E 66-80x定价了至少3年的完美执行。任何执行瑕疵（产能瓶颈、供应链延迟、客户推迟）都会导致戴维斯双杀
- nVent（NVT）做同样的事但P/E只有35x——同赛道估值差一倍说明市场给了VRT非理性溢价
- 风冷技术持续进步（后门散热、直接芯片风冷），液冷渗透率可能不及预期

**MRVL——这个瓶颈能被绕过吗？**
- **能。** 最大的威胁来自客户自研：Google TPU已到第7代、AWS Trainium已大规模部署、Meta MTIA正在爬坡
- 当hyperscaler自研芯片成熟，MRVL的ASIC设计服务价值被内部化——这是MRVL面临的**结构性威胁**，不是周期性波动
- Broadcom在ASIC领域有$730亿积压订单，MRVL的体量远小于此——**MRVL是配角，不是瓶颈的主导者**

**MU——终端需求放缓50%会怎样？**
- DRAM/NAND是标准品，需求下降50% = 价格暴跌50%+（存储的需求弹性极大）
- 历史先例：FY2023收入从$308亿暴跌到$155亿（-50%），毛利率从45%变成-9%，净亏$58亿
- 当前P/B 9.6x在下行周期会迅速回归2-3x → 股价可能下跌60-75%
- **结论：MU对终端需求下行极度敏感，约束能力几乎为零**

**LRCX——管理层过去有没有在高点增发稀释？**
- 没有增发稀释——反而在持续回购（连续5年减股本2-3%/年）
- 但CEO在$390高点精准减持$1170万——恰好在7月暴跌前夜
- 这不是增发稀释，但**内部人在高点离场的信号明确**
