## 0. 结论速览（芒格式）

> "4月的交易把微软从'OpenAI 的人质'变成了'OpenAI 的地主'——放弃了独家，换来了 $228B 股权、$250B 采购承诺和锁到 2032 年的 IP 钥匙。牌桌上所有人现在互相持股：亚马逊投 OpenAI 又养 Anthropic，微软投 OpenAI 又从 Anthropic 赚了 $3.2B。**当没有确定赢家时，收租的人比押注的人睡得香。** 微软现在收三份租：云的租、席位的租、OpenAI 的租。"

- **行业格局评分：7.5/10**（前值 2026-08-18 为 8.0；扣分：Azure 独家权丧失、AI coding 产品力落后、折旧年限 15→25 年的会计信号；加分：机构仓位已大幅出清、$678B 合同化需求）
- **逆向结论**：三大死因没有任何一个在 3 年内有清晰引信，但"折旧表"是全场最诚实的告密者
- **一句话结论**：持有 60 股不动——微软已从 8 月"拥挤交易核心受益者"变成 9 月"仓位最干净、合同最厚实的 AI 收租人"，芒格会继续拿着；盯两个诚实指标：Copilot 席位增速、FY27 折旧计提。

### 1.2 AI 编程三国杀（2026 年中，多源）

**份额口径分歧本身就是信号**：Copilot 靠分发占用户基数，Claude Code/Cursor 靠产品占心智。Ramp 数据显示 Cursor 从 41%（2025.6）回落至 26%（2026.5）——**这个市场内部一年就洗一次牌，没有人有永恒的产品护城河**。GitHub 真正的护城河不在助手，在代码托管本身（repo + CI + 企业合规）——Agent 写完代码仍要提交到 GitHub。芒格：*"助手是汽车，GitHub 是公路。汽车厂换了几轮，公路还在收过路费。"*

### 1.3 办公/Agent 战场

- M365 用户 **4.3 亿**，Copilot 付费席位 **3000 万**（4 月 2000 万 → 7 月 3000 万，渗透率仅 ~7%）——仍在早段

- 关键细节：**微软在 Copilot 里接入了 Anthropic Claude 模型**（多模型编排）——在 OpenAI 之外自留后门

## 2. 反转检验：什么会杀死微软？

芒格方法：先问死因，再看估值。主观概率为 10 年视角、致"永久性资本损失 ≥40% 回撤且不可恢复"的量级。

### 死因一：AI 资本开支的回报崩塌——"折旧悬崖"（概率 ~20-25%）

- 单季 capex $41B（+69%），FCF 降至 $19.6B（-23%）；FY27 capex ~$175B
- **最刺眼的细节**：微软把办公楼和数据中心折旧年限从 **15 年延长到 25 年**，从而把 2026 日历年 capex 预期从 $190B "降"到 $175B。芒格式反应：*"延长折旧年限不会消除成本，只会把成本推给未来的股东。当一家以会计保守著称的公司开始用折旧政策调节利润表，这本身就是现金流压力的招供。"*
- 引信：2027-28 年如果 AI 收入增速回落而折旧计提陡增，利润率将被两头挤压；存储芯片涨价（2026 年 ~$25B 纯粹为组件涨价买单，不买任何增量产能）在推高单位成本
- 对冲证据：RPO $678B（+84%，剔除 OpenAI 仍 +25%，**本季环比增量全部来自非前沿实验室的企业客户**）——这是合同，不是预测。芒格承认可见性，但提醒：*"合同是需求的真实收据，折旧表是成本的真实收据。两个都看，别只看前一个。"*

### 死因二：OpenAI 集中度反噬与联盟价值稀释（概率 ~15-20%）

- 1 月口径：**~45% 商业 RPO 与 OpenAI 相关**；4 月重构后 Azure 独家权废除（OpenAI 模型次日即上 AWS Bedrock）；传 OpenAI 与 AWS 谈 $50B 云合同；OpenAI 冲刺 $1T IPO——上市后其采购决策将受公开市场股东审视，$250B Azure 承诺的执行节奏存变数
- 对冲证据（这一条比 8/18 时显著增强）：26.79% 股权价值 **$228B（17.6 倍回报）**、OpenAI **$250B Azure 采购承诺**、20% 收入分成**设上限**（封顶约 $38B 至 2030，防 OpenAI 爆量后分成失控反噬条款）、**IP 权利锁定至 2032 年且删除了 AGI 条款**（把模糊的"AGI 触发"换成确定的日期——用确定性换独家性，这是芒格会鼓掌的交易结构）
- 引信：OpenAI IPO 后治理独立化 + 多云采购分散化快于 Azure 锁定节奏

### 死因三：软件护城河被 Agent 原生公司侵蚀（概率 ~15%，慢性）

- AI coding 已是前车之鉴：GitHub Copilot 分发第一但产品力第三（SWE-bench 68.2% vs Claude Code 80.8%），且已改用量计价——**席位定价向用量定价迁移是 ARPU 结构性下修的先声**
- Office 席位模型的理论风险：若 Agent 按"完成的工作量"而非"人头数"收费，4.3 亿席位的存量反而成为被颠覆的标的
- 对冲证据：Copilot 30M 席位且 90% F500 覆盖、提价落地、Agent 生态 15 倍增长、Barclays 15k→100k 席位式扩张——目前是"渗透率故事"而非"流失故事"；Graph 数据层 + 合规 + 集成分发的转换成本没有松动迹象

**综合判断**：三大死因十年合计"严重损伤"概率 ~35-40%，"杀死"概率 <15%。没有任何单一死因在 3 年内有清晰引信——**这不是一家会被突然杀死的公司，是一家会被慢慢计息的公司**（折旧与集中度都是慢变量）。真正的快变量是估值：YTD +2.86%、机构目标均价 $565.88、95% 买入评级——好公司不便宜，这是持有的主要成本。

## 3. AI 联盟格局：芒格怎么评"既结盟又竞争"

4 月 27 日重构后的新格局（多源交叉：CNBC/Directions on Microsoft/交易条款解析）：

| 条款 | 重构前 | 重构后（2026-04） |
|---|---|---|
| 云独家 | Azure 独家 | **废除**（OpenAI 可上任何云） |
| IP 权利 | 模糊，挂钩"AGI 认定" | **锁定至 2032**（AGI 条款删除） |
| 收入分成 | 20% 无上限 | 20% **设上限**（至 2030，约 $38B） |
| 股权 | ~32.5%（估算） | **26.79%**（PBC 正式化，$228B @ $852B 估值） |
| 采购 | 无硬承诺 | **OpenAI 承诺采购 $250B Azure** |

**芒格的三段评语**：

1. **"这是从人质到地主的升级。"** 旧结构的致命处是 AGI 条款——OpenAI 董事会一纸"AGI 认定"就能重议微软的模型访问权，模糊权力在对方手里。新结构用独家权换确定日期：IP 到 2032、分成到 2030、$250B 采购承诺。**把二元尾部风险换成已知期限，拿着 $228B 敞口时，确定性比独家更值钱。** 微软这笔交易做对了。

2. **"所有人都在买所有人的保险，说明没人知道谁赢。"** 看资本地图：亚马逊一边重仓 Anthropic、一边 2026 年追投 OpenAI 最多 $50B；微软投 OpenAI 27%，本季却从 Anthropic 持仓录得 $3.2B 收益，还在 Copilot 里接入 Claude；OpenAI 上 AWS Bedrock、谈 AWS 大单。这不是背叛，是理性玩家在不确定下的对冲。**芒格的推论：当模型层没有锁定赢家时，价值向两端的确定性资产迁移——最上游的算力和最下游的分发。微软两头都占。**

3. **"但别把保险当护城河。"** 竞争性合作的另一面：OpenAI IPO（传 $1T 估值）后，26.79% 股权是财务资产而非战略资产——锁定期后微软可减持，OpenAI 也可更冷血地分配采购。2032 年 IP 到期日就是这个联盟的真实倒计时。**在那之前，微软必须把 Maia 芯片、自研模型、Foundry 平台从"备胎"变成"主力"——目前进度合格但不超前。**

## 4. 拥挤度：从"拥挤交易核心"到"反向拥挤"（本次研究最大更新）

8/16 wave1 的结论是"MSFT 是拥挤交易核心受益者，回调时 beta 最大"。**9 月的仓位数据要求修正这个判断：**

- **摩根士丹利 Q1 2026 13F 报告：微软被主动机构低配 -1.86%**（英伟达 -2.39%、苹果 -2.32%、亚马逊 -1.24%）——七巨头整体平均低配 -125bp。真正的拥挤交易已迁移到 AI 存储/半导体设备链（闪迪超配 +2.16% 创历史新高）
- **机构持股比例 85.5% → 72.8%，环比砍仓 -12.23%**——主动仓位出清幅度为巨头中罕见
- 但情绪仍拥挤：**95% 机构买入/增持评级、0 卖出**，目标均价 $565.88（较现价 +13%）——"认知高配、仓位低配"的背离结构
- 逆向买家已在场：Ackman Q1 建仓 $2.09B（占其基金 >15%，理由是"市场低估 OpenAI 合作 $200B"）；Thiel 从高 beta 芯片股轮入微软；董事 Stanton $2M 买入——**十年最大内部人增持**
- 价格结构印证：1-6 月从 $551 高点最深跌至 $348.54（-37%，正是"拥挤交易回调 beta 最大"的兑现期），7/29 财报（RPO +84%）后单日 +8%，现反弹至 $498（较低点 +43%）

**芒格结论**：*仓位出清后的下跌有承接，没有出清的下跌才可怕。* 8 月的"拥挤"已在 6 月的 -37% 里付过账了。当前风险结构已变：不再是"拥挤瓦解"风险，而是"情绪仍满仓看多但价格已从低点涨 43%"——追高者的回撤风险。对 $279 成本的持有人，这是别人的问题。

## 5. 芒格逆向结论与评分

**逆向清单（如果我现在空仓，敢不敢买入？）**：敢，但会等回调——$498 对应 forward P/E ~28x（非 GAAP 口径），高于我喜欢的价格，低于致命的价格。$279 的持仓成本是运气，不是能力；**持有它不需要运气，只需要不动**。

**评分：7.5/10**（8/18 前值 8.0）
- -0.5：Azure 独家权丧失 + AI coding 产品力落后（SWE-bench 硬差距）
- -0.25：折旧年限 15→25 年的会计信号 + FCF -23%
- +0.25：机构仓位出清 + RPO $678B 合同化需求 + Copilot 席位 3 个月 +50%
- 净变化 -0.5：护城河没变宽，但确定性和筹码结构变好了

**监测清单（按重要性排序）**：
1. FY27Q1 财报（10 月底）：Azure +45% 指引兑现 + 剔除 OpenAI 后 RPO 增速
2. Copilot 付费席位：能否从 30M 向 50M 加速（渗透率故事是否成立）
3. FY27 折旧计提与 FCF：会计延期的账单何时到
4. OpenAI IPO 进程与锁定期后微软减持动向
5. GCP 份额：15% → 17% 则 Azure "横盘换利润"策略失效
