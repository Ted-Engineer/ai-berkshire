## 二、分部重构的财务影响：透明度溢价 vs 掩饰担忧

这是本次重研的核心命题。巴菲特看会计变更只问三件事：**谁受益、何时受益、代价是什么。**

### 2.1 正面：透明度溢价的机制

1. **Azure 可单独估值（SOTP 变得可行）**。市场多年抱怨"只给增速不给收入"，如今 Azure 每季美元收入可直接对标 AWS/Google Cloud。若市场对"纯 consumption 云基础设施"给 8-10x PS（参照 AWS 隐含估值），仅 Azure >$1,000 亿收入就支撑 ~$8,000-10,000 亿市值，占微软当前 $3.7 万亿市值的 22-27%——其余业务（M365、游戏、搜索、LinkedIn，合计 ~$2,300 亿收入、更高利润率）事实上被市场按 ~12-13x PE 定价。**披露越清晰，隐藏价值越容易被看见。**
2. **管理层敢披露 = 对增长有信心**。如果 Azure 在减速，把美元收入晒出来只会让减速更醒目。FY27 Q1 指引 +44-45% cc 与披露决策同日给出——这是"把牌摊开"的姿态。
3. **两年重述数据**降低了对比断裂风险，卖方建模迁移成本可控（已有 FY27 Q1 新分部收入指引）。
4. "Agents and Infra" 的命名本身就是战略声明：微软自我定位为 AI 时代的"智能层+基础设施层"复合体，Nadella 原话"AI 正在模糊产品边界"。

### 2.2 警惕：三起口径变更同年发生

**折旧年限 15→25 年（7 月）、租赁重分类降 CapEx 口径（7 月）、分部重构+Azure 口径变窄（9 月）——同一年内三起报告口径变更。** 芒格会问：一家生意这么好的公司，为什么 suddenly 这么热衷于重新安排报表？

具体到分部重构的两个疑点：

1. **Azure 口径变窄方向可疑**。剔除的 GitHub 云、Security Copilot、医疗云，恰好是"非纯 consumption"业务——留下的是增速最快、故事最顺的部分。旧口径 FY26 全年 >$1,000 亿、+33%；新口径基数会更低、增速会显得更高。**基期切换的第一季（10 月底），同比增长率将不可比地"变好"**——投资者必须盯住两年重述表里新口径的真实基数，防止被"口径红利"骗到。
2. **OpenAI 关联交易占比**。Stifel 估算 FY26 Azure 增长约一半来自 OpenAI——这是关联方收入（微软既是 OpenAI 股东又是其算力供应商）。分部披露后这笔收入的规模与变化将更可见，这是**双刃剑**：若 OpenAI 贡献占比下降而 Azure 增速仍 >40%，是最强验证；若披露显示增长高度依赖单一关联客户，市场会立即重定价"收入质量"。

### 2.3 市场重定价路径推演（10 月底首份新报表 = 催化剂）

| 情形 | 概率 | 市场反应 |
|---|---|---|
| 新口径 Azure 增速 >40% 且 OpenAI 依赖度下降 | ~40% | 透明度溢价兑现：SOTP 重估，挑战 52 周高点 $549 |
| 增速 35-40%，OpenAI 依赖度持平 | ~40% | 中性：按 forward EPS 定价，区间 $500-552 |
| 增速 <35% 或依赖度上升/重述基数争议 | ~20% | 反向重定价：质疑口径红利，回踩 $480-450 |

**巴菲特判词**：透明度本身永远是对的——"阳光是最好的消毒剂"。但同一年三起口径变更意味着**分析可比性被系统性削弱**，投资者必须自建还原表（本组合已有：德银租赁还原口径）。我的倾向：这次重构净评价为正（Azure 美元披露的价值 > 口径变窄的损失），但把它计入"信息透明度"评分的上调，而不是给管理层会计诚实性加分——诚实性的减分项仍挂在折旧年限 15→25 上（那是真金白银的利润前置）。

## 三、FY27 FCF 复核：$47 亿 vs $653 亿的口径之争

9 月无新增 CapEx 数据（Q4 后静默期），但口径分歧值得摆清楚——这决定"FCF 悬崖"有多深：

| 口径 | FY27E OCF | FY27E CapEx | FY27E FCF | 含义 |
|---|---|---|---|---|
| **德银（含租赁还原）** | ~$2,157 亿 | ~$2,149 亿（含融资租赁） | **~$47 亿** | 最严口径：FCF 趋近于零（-93%），FY28 回升 ~$184 亿 |
| **管理层口径（账面）** | — | ~$1,750 亿（经营租赁剔除后） | "保持为正" | 官方承诺，但口径已窄化 |
| **Barchart/inkl（宽口径）** | $2,403 亿（61.6% OCF margin × $3,901 亿收入） | $1,750 亿 | **~$653 亿** | 不还原租赁——**这个口径会高估 FCF**，因为经营租赁的现金照样付，只是不计入 CapEx 行 |

三口径对照的结论不变反强：**真实杠杆 FCF 介于 $47 亿（德银严口径）与 $653 亿（宽口径）之间，且宽口径的"舒服"正是会计变更制造出来的错觉。** 经营租赁租金计入经营现金流流出而非 CapEx，所以宽口径 FCF 高估的幅度 ≈ 新增经营租赁的年度租金——这正是 15→25 年折旧变更搬移的同一批资产。穆迪"持续资本开支可能威胁信用质量"的警告针对的就是全口径承诺（未生效租赁承诺 $3,291 亿，FY27-FY33）。

维持 9/2 判断：**FY27 是 FCF 危险线之年**。对冲因素依旧（2/3 CapEx 投向短周期 CPU/GPU 可快速收缩；RPO $6,780 亿 +84% 提供 2.3 年订单能见度——"先有订单后建产能"）。9 月中旬的提息幅度将是第一个实证检验点。

## 六、巴菲特视角评述

**这生意的本相（分部重构后看得更清了）**
- Agents and Infra（Azure+M365 云+服务器）≈ 营收的 ~76%（FY27 Q1 指引 $751.5-757.5 亿 / $898.5-909.5 亿总收入），是"卖算力+卖智能"的复合基础设施生意；Devices and Consumer（~$150 亿/季）是消费侧长尾。**微软实质上正在变成"企业 AI 公用事业+应用层税"**——这既解释了 46.8% 营业利润率的韧性，也解释了为什么 CapEx/营收要冲到 35%+。
- 增长引擎的成色：Azure FY26 >$1,000 亿（+33%）、Q4 +42%、指引 +44-45%；Copilot 3,000 万付费席位（环比 +50%）；RPO $6,780 亿（+84%，2.3 年能见度）。订单先行、产能后建——性质是 BNSF 式需求驱动扩产，不是 dot-com 式产能赌注。
- 但硬币的另一面：Stifel 估算 FY26 Azure 增长约一半来自 OpenAI。**当最大增长客户同时是被投企业，收入的"市场检验度"要打折**——10 月新报表首次让这个数字可计算，这是分部重构送给我们最重要的礼物。

**会计诚实性记分卡（老巴最爱的一页）**
- 折旧年限 15→25：利润前置，现金分文未省。**记减分，挂在账上。**
- 租赁重分类（CapEx 口径 $1,900→$1,750 亿）：投资计划未变，报表变好看。**记减分。**
- 分部重构 + Azure 美元披露：透明度实质提升，虽口径变窄但附两年重述。**记加分——三起变更中唯一方向正确的。**
- Anthropic $32 亿投资收益计入 GAAP 净利（FY26 Q4 +31% 有水分，non-GAAP +22% 才是真相）：非操纵但需剔除，本报告全程双轨呈现。**中性。**

**"让利润奔跑"的天平（今日更新）**

## 八、结论

1. **持有，不加仓。** 现价 $510 处 forward 中性 $552 下方 7.6%（上行空间在），保守 TTM 中性 $484 上方 5.4%（安全边际已失）——持有逻辑从"便宜"切换为"FY27 EPS $19.72 兑现 + 10 月透明度重估期权"。
2. **止损执行阶梯规则，本周进入戒备状态。** $520 触发线距 9/3 高点仅 1.0%：一旦站上 $520，止损 $450→**$480**（锁定 +71.8%，最大回撤收窄至 -7.7%）；站上 $552 再上移至 $510。触发 $550+ 且占比 >11.5% 时按 9/2 联动条款评估减仓 10-15 股（team-lead 决策项）。
3. **两个近端催化剂排期**：① **9 月中旬年度提息**（约 9/14-16，去年 9/15）——幅度 ≥10%（→$1.00/季）即管理层对 FY27 FCF 为正的真金白银背书；若仅维持 $0.91 或幅度 <5%，视为 FCF 压力的第一声警报，评分再降。② **10/27 FY27 Q1 财报**——新分部口径首秀：盯 Azure 美元收入增速（>40% 佳 / <35% 警报）、OpenAI 依赖度（重述表可算）、CapEx 是否 >$500 亿、单季 FCF 是否转负。
4. **分部重构净评价为正但保持警惕**：透明度溢价期权（SOTP 重估，挑战 $549 高点）与口径红利陷阱（新口径基数更低、增速虚高、OpenAI 依赖）同在一张报表里，10 月底用重述表说话，不预设结论。
