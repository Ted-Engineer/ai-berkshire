### 3.2 OCF $183B 覆盖 CapEx 的健康度

FY26 OCF/CapEx（现金口径）= 1.58x。即便 CapEx 再升 50%，经营现金流仍可完全覆盖现金资本开支——**偿付能力无虞**（这区别于靠融资输血的 AI 纯概念股）。问题不是"能不能覆盖"，而是**机会成本**：每投入 $1 CapEx，当前只换来 50% 净利率生意的增量，而股东拿到手的 FCF 连续两年萎缩。管理层自身也只敢承诺"FY27 FCF 为正"（Amy Hood，7/29 电话会，CNBC）——这一措辞本身就是管理层对 FCF 转弱的默认。

### 3.3 CY26 CapEx 情景下的 FY27-28 FCF 轨迹（calc 工具输出）

已知锚点：CY26 CapEx 原指引 **$190B（+61%）**（tastylive 财报前综述）；7/29 电话会维持 CY26 计划不变，但因折旧年限变更与更多经营租赁化，**新口径下 CapEx+融资租赁 ≈ $175B**；FY27 街道预期 ~$220B（+20-30%）。现金 CapEx ≈ 口径值 × 0.76（FY26 实测 115.9/152）。

| 情景 | OCF 假设 | CapEx（口径/现金） | FY27E FCF | 工具输出 |
|---|---|---|---|---|
| 乐观（CapEx纪律 $160B） | +18% → 215.9 | 160 / 122.1 | **≈ $93.8B（+40%）** | `182.935*1.18-160*0.763 = 93.78` |
| 中性（CY26 $175B，FY27 $200B） | +12% → 204.9 | 175 / 133.5 | **≈ $71.4B（+6.5%）** | `182.935*1.12-175*0.763 = 71.36` |
| 悲观（FY27 $220B+） | +6% → 193.9 | 220 / 167.9 | **≈ $26.1B（-61%）** | `182.935*1.06-220*0.763 = 26.05` |

- **FY28 轨迹**：若 CapEx 增速降到 +10% 以内且 OCF 保持 +15%，中性偏乐观下 FCF 回到 $90-110B（FCF yield 从 1.86% 修复至 2.5-2.9%）；悲观情景则 FY28 仍被压在 $40-60B。
- 注意 $26.7B 应付 CapEx 将在 FY27 兑现，实际现金 FCF 比上表再低一档；管理层"FY27 FCF 为正"的保守措辞与悲观情景吻合。

### 3.4 折旧时间表对利润率的机械压力测算

- 折旧费用轨迹：$15.2B（FY24）→ $22.0B（FY25）→ $34.3B（FY26）→ **FY27E $50-58B**。驱动：服务器/网络设备毛额 $215.9B（+62.5%，寿命仅 2-6 年）、建筑毛额 $182.7B（+32.5%）、总 PP&E 毛额 $431.8B（+44.6%）、累计折旧 $118.7B。
- 会计缓冲 1：**建筑折旧年限 15→25 年**——存量建筑每年省折旧 **$4.87B**（calc：`182.749*(1/15-1/25) = 4.87`）。会计利润受益，但服务器折旧（2-6 年）才是大头，年限变更掩盖不了其指数级爬坡。
- 会计缓冲 2：更多数据中心租赁从融资租赁转经营租赁——表观 CapEx 与租赁利息下降，成本转为经营租赁费用，报表更"轻"，经济实质不变。
- **机械测算（中性）**：FY27E 增量收入 ~$53B × 增量经营利润率 ~60% = +$32B；增量折旧 +$16-24B → 经营利润仅增 $8-16B → **经营利润率 43.5%-45.3%（vs FY26 46.8%，降 1.5-3.3pp）**。季度轨迹（48.9%→45.1%）已提前演绎。利润仍在增长，但"利润率长牛"叙事在 FY27-28 结束——除非 Azure 增速能持续对冲。
- 巴菲特视角注脚：折旧是真实、递进、不可协商的成本；延长折旧年限改变的只是报表节奏。芒格式提醒——当你看到一个 CFO 同时上调 CapEx 和拉长折旧年限，应把报告利润率打 8-9 折看待。

## 七、巴菲特视角结论 + 纪律裁定

### 7.1 投资论点重审

**生意本身仍是世界级**：46.8% 经营利润率、40% 净利率、ROIC 26%、RPO $678B（+84%）提供史上最强的收入可见性、Copilot 30M 付费席位（4 月 20M → 6 月 30M，3 个月 +50%）、Azure 增速 40% → 43% → 指引 45% 逐季加速、Windows OEM 提价 10% 的隐性定价权。护城河在变宽，不是变窄。

**但三个巴菲特式警讯**：
1. **所有者收益与会计利润裂口**：净利 +31.3%（核心 +20-22%）而 FCF -6.5%，FCF/净利 50%。每一美元报告利润只有一半变成可分配现金，其余变成 GPU 与混凝土。芒格说过：世上最危险的事，是用报告利润给资本开支找理由。
2. **资本纪律信号弱化**：CY26 $190B（+61%）CapEx、FY27 继续增长、CFO 只承诺"FCF 为正"；同时延长折旧年限（年省 ~$4.9B）+ 租赁表外化——两个让报表更好看的会计动作与史无前例的 CapEx 同时出现。不是造假，但方向性信号明确：增长优先于股东现金回报。
3. **关联方循环收入**：OpenAI 贡献 $24.1B 收入（7.3%）+ $6.0B 应收 + $13B 出资承诺。用巴菲特的话说，这像是"左口袋注资、右口袋确认收入"的结构——虽然合同上真实、法律上清洁，但质量的含金量需打折。

**综合评分（10 分制）**：盈利质量 8.5/10（核心业务顶级，重估收益掺水）；现金流质量 5.5/10（覆盖尚可、方向恶化、FY27 关键）；资产负债表 7.5/10（净债务 $52B 但多为租赁、利息覆盖 50x、无融资压力）；估值 5.5/10（PE 带中位、FCF yield 历史低区、加权上行 +7.2% 薄）。**总评：优秀的公司、中性的价格、恶化的现金转化——持有合理，加仓证据不足。**

### 7.2 $436 止损裁定（核心纪律问题）

**裁定：维持 $436 GTC，不立即上移至 $455。** 理由：

1. **技术结构支撑当前位**：$436 恰好位于 7/29-30 财报跳空缺口（$390.54→$451.10）下沿 $451 之下的真空区，且紧贴 200 日均线（$432.17）上方——缺口+年线构成支撑簇，跌破 $436 = 缺口完全回补+年线失守，属趋势破坏信号而非噪音。 calc：`436/482.87-1 = -10.7%`（任务口径 -9.7% 为 436/482.87 差值，工具输出 0.1075 即距离 10.75%——以现价计回撤 9.7%/距离 10.7% 表述一致）。
2. **$455 太近、易被噪音扫损**：$455 距现价仅 -5.8%（calc：`455/482.87-1 = -0.06`），落在 8 月成交密集区（$480-506）下沿之内；财报周隐含单周波动 6.5%（tastylive 期权口径），一次普通回调即可触发，随后眼看 $642 情景展开。风险 Agent 规则"**上穿 $520 后上移 $455**"的触发条件从未满足（8 月高点收盘 $506.06，未破 $520）——纪律的意义在于按规则执行，而非事后挪动门槛。
3. **盈亏结构仍极度有利**：即便 $436 离场，锁定 +30.9%（成本 $333.194，calc：`436/333.194-1 = 0.31`）；最大回吐 $2,812（组合 NAV 影响 ≈ -0.9%），为 +44.9% 浮盈的可接受保险费。
4. **催化剂日历明确**：10/30（10 月底）FY27Q1 财报是 Azure 45% 指引的验证时点，届时信息增量最大，止损调整应在信息之后而非之前。

**附加规则（预承诺，供组合经理批准）**：
- **规则 A（沿用）**：10/30 前若收盘上穿 $520 → 止损上移至 $455（原风险 Agent 建议）。
- **规则 B（新增，事件驱动）**：10/30 财报若 Azure ≥45% cc 兑现 且 FY27 CapEx 指引 ≤$210B → 无论价格是否过 $520，止损上移至 max($480, 50DMA)，锁定财报后水平。
- **规则 C（新增，恶化离场）**：若 10/30 Azure <42% 或 CapEx 指引 >$230B 且 FCF 无改善措辞 → 不等止损位，主动减至 ≤5% 仓位（论点受损优先于价格止损）。
- 财报前若无消息跌破 $470：判定为噪音，不动作。

### 7.3 仓位与加仓线

- **9.5% 仓位：合理，维持**。加权目标 $517.5（+7.2%）上行有限 + FCF 质量未修复 → 不加仓；RPO 可见性 + 生意质量 + 催化剂在途 → 不减仓。9.5% 处于单一持仓合理带上沿，本质是"用波动换质量"的持仓。
- **加仓线：维持前裁决——$430 以下不再自动加仓**。若股价回到 $430-436（fwd PE ~21.5x，5 年带下沿上方），估值合理但**基本面叙事（FCF 下滑、折旧爬坡、OpenAI 循环）并未改善**，且 $436 止损近在咫尺，加仓=提高被同一颗子弹打中的概率。巴菲特式回应：好公司遇上不干净的现金转化，宁可错过，不做接刀。若未来 FCF/净利回到 >70% 且 Azure 保持 40%+，可重开加仓评估——但那是 FY27Q2 之后的事。
