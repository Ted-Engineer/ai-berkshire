### 1.3 OpenAI 重构的判断质量（4/27 修订协议，微软官方博客全文验证）

2026-04-27 微软/OpenAI 发布修订协议（此前 2025-10 已重构一轮），六大条款：
1. 微软仍是 OpenAI **主要**云伙伴，OpenAI 产品**优先**在 Azure 上线——除非微软"不能且选择不支持"必要能力（**单边退出阀门**）；
2. OpenAI 产品可部署到**任意云**（多云解禁）；
3. 微软对 OpenAI IP（模型与产品）的许可**延至 2032 年，但改为非排他**；
4. 微软**不再向 OpenAI 支付**收入分成；
5. OpenAI→微软的收入分成**延续至 2030**，比例不变、**设总额上限**；
6. 微软继续作为大股东直接参与 OpenAI 成长；双方合作下一代芯片。

**判断质量评估：B+/A-**。得：把一个法律纠缠、清算优先级复杂的关系（HLBV 计量之复杂即是证据）简化成"优先供应+分成现金流+股权"；换取 IP 至 2032 和 Azure 优先权；停付分成改善自身经济性。失：非排他 IP 许可使 2032 年后模型层护城河存疑；"primary cloud"措辞弱于原排他条款；分成设上限意味着 OpenAI 规模越大、微软分享比例越递减——管理层实质上承认：**未来价值在 Azure 算力与分发，不在 OpenAI 股权本身**。这是清醒而非浪漫的判断，符合李录"看商业模式而非故事"的标准。

## 2. OpenAI 关系风险（重点章节）

### 2.1 会计与传染路径（10-K Note 验证）

| 维度 | 事实 | 风险含义 |
|---|---|---|
| 会计处理 | 权益法，~25%（as-converted），**HLBV**（假设清算账面价值）法计量 | 不并表；亏损按清算优先级折算，非按持股比例 |
| FY26 损益影响 | **+$4.963B**（含 Recapitalization 稀释收益 $6.5B 量级、计入 Other income） | GAAP EPS +32% vs non-GAAP +22% 的全距 |
| FY25 对比 | -$3.62B（净损失） | FY27 若 OpenAI 亏损扩大且无稀释事件，重回拖累 |
| 资产负债表 | 权益法投资合计 $12.0B（FY25 $6.0B） | 表内敞口有限（占市值 0.3%） |
| 资金承诺 | 承诺 $13.0B，已投 $11.9B | 剩余 $1.1B，追缴义务小 |
| **收入传染** | **FY26 确认来自 OpenAI 收入（含分成）$24.1B = 总收入 7.26%**；应收 $6.0B | **真正的大敞口在收入端而非投资端** |
| RPO 结构 | RPO $678B 含 OpenAI Azure 承诺；**剔除 OpenAI 仅 +25%** | 头条 +84% 一半以上是单一关联方承诺 |

### 2.2 剩余风险清单（重构后）

1. **股权价值波动**：OpenAI 传 2026-06 已递交 IPO 申请（$850B 估值/$25B 收入口径，**来源为低置信度媒体，需以正式招股书为准**）。若 IPO 落地，微软 25%（as-converted）面临可观察定价——可能确认大额收益，也可能暴露 HLBV 账面值与市价的巨大落差；上市后股价波动将传染至微软"AI 资产"叙事。
2. **优先权条款的双刃剑**："除非微软不能且选择不支持"给了微软退出权，但也给了 OpenAI 多云合法化路径——Anthropic（GPT-5.6 竞品，且微软自己持有 Anthropic 股权并确认 $3.2B Q4 收益）等模型在 Azure 目录内 11,000 个模型中竞争，OpenAI 优先权实际价值取决于 Azure 供给紧张程度。
3. **分成上限**：OpenAI→微软分成至 2030 设总额上限；OpenAI 规模化越快，上限越早触顶，微软增量分享递减。
4. **2032 IP 悬崖**：非排他许可到期后，若 MAI 自研模型（MAI-Code-1-Flash、MAI Thinking 1 等）届时未能对齐前沿，Copilot/Foundry 的模型底座依赖外部。
5. **循环性与对手方偿付**：OpenAI 2026 年预计亏损 ~$14B、Q1 亏 $3.7B（收入 $5.7B）、寻求 ~$100B 融资（1 月报道）；其 Azure 承诺（计入微软 RPO）的偿付依赖持续融资/IPO。**若 OpenAI 融资受阻，$24.1B 年收入+新承诺增速将同步受压，应收 $6.0B 存在回款周期拉长风险**。这是 Azure+45% 兑现概率中最大的单一对手方变量。
6. **诉讼关联**：Musk 诉 OpenAI/微软案庭审已排期（4/27 GeekWire 报道），判决可能重新定义股权/许可结构。

**李录视角**：把 OpenAI 从"子公司幻觉"重构为"优先供应商+小股权+封顶分成"，是把不可控变为可控的正确动作。真正的敞口不是那 $12B 账面值，而是**收入端 7.3% 的关联依赖 + RPO 中 OpenAI 承诺对头条增速的放大效应**。管理层用"剔除 OpenAI +25%"的披露主动坦白了这一点——信息披露质量高，应予肯定，但投资者必须用剔除口径做保守估值。

## 4. 业务风险：CapEx 周期顶部判断错误的代价

**数字链（官方）**：FY24 $44.5B → FY25 $64.6B → **FY26 $115.9B（+79.5%）**；Q4 FY26 单季 $41B（现金 PP&E $35.8B+融资租赁 $5.6B）；**Q1 FY27 指引 >$50B**；CY26 口径 ~$175B（重分类后）。累计 2022 年以来投入 ~$280B（Guardian 口径）。

**若 AI 需求减速，$190B→$175B 级别投入的代价**：
1. **折旧洪峰**（见 §5）：FY26 D&A 已 $38.5B（+31%）；2/3 CapEx 是 5–6 年寿命的 GPU——FY27–28 D&A 将向 $55–65B 量级爬坡（推算，中置信）。若收入减速而折旧刚性上升，营业利润率将击穿"降幅 <1pt"指引。
2. **减值风险**：科技资产迭代快（H100→Blackwell→Vera Rubin 两代一代差），需求若逆转，短寿命资产残值假设（以及 15→25 年的新年限假设）将被审计追问。10-K 已自列风险："收入可能不会在预期时间框架或预期水平上实现"。
3. **行业同步性**：AWS $220B + Google 高投入 + Meta $130–145B——四家同步下注意味着**供给释放高度同周期**，2027–28 年利用率与定价是全行业未经验证的假设。
4. **宏观信贷传染**：AI 数据中心债务已登华尔街信贷风险观察榜首（BofA 5 月"air pocket"警告）；BofA 数据中心融资管道 ~$250B。若信用市场对 AI 债定价收紧，二线买家（CoreWeave 类）需求萎缩会回传染至云巨头出租率。微软自身零新债、FCF 为正，是行业中最不依赖外部信贷的玩家——**相对风险最小，绝对敞口仍大**。

**Azure+45% 不兑现的股价弹性（历史锚）**：
- 2026-04-29（FY26Q3）：业绩超预期但因 CapEx 上调至 $190B，次日跌（周线 -2.4%）——**CapEx 恐惧单独可致 -3~-8%**；
- 2026-07-29（FY26Q4）：Azure 43%+指引 45%，周线 +21.7%（$381.7→$464.7）——**兑现可致 +8~15%/日**；
- 2026-06-27 前后"AI 泡沫回调"期间股价 $373–390——**叙事杀可达 -20% 量级**。
- 结论：45% 指引已部分定价（7/29 以来 +21.7%），**下修的下行弹性（-10~-15%）大于上修的上行弹性（+3~8%）——赔率不对称向下**。

## 5. 财务风险

### 5.1 折旧洪峰时间表

- FY24 $21.0B → FY25 $29.4B → FY26 **$38.5B**（+31%）。CapEx 峰值（FY26–27）传导至 D&A 峰值按 5 年加权平均寿命推算在 **FY27–FY29**。
- 管理层对冲动作（7/29 宣布）：**数据中心/办公楼折旧年限 15→25 年**——FY27 营业利润"最小受益"，主要效果是更多未来数据中心租赁从融资租赁转经营租赁（从而**退出 CapEx 统计口径**，$190B→$175B 的调整即来源于此）。**李录视角的警觉点：这是会计口径的减压阀，不是经济折旧的消失**；经营租赁化同时把成本推入未来租赁费用（Q4 电话会已提示利息费用含数据中心融资租赁利息）。FY27 Q1 指引 OI&E 约 -$100M（利息支出上升）。
- 容忍度标尺：FY27 指引营业利润率降幅 <1pt + 全年 FCF 为正 = 管理层自我约束的红线。**跌破任一即证伪**。

### 5.2 FCF 压缩容忍度

FCF：FY25 $71.6B → FY26 **$67.0B**（-6.5%），占净利 50%、占收入 20%。Q4 单季 FCF $19.6B。分红 $26.4B/年 + 回购 $16.7B = $43B，已相当于 FCF 的 64%。若 CapEx 再增 20%（FY27 >$139B）而 OCF 增速放缓至 +15%，FCF 将降至 ~$55–60B——**覆盖股东回报后余量归零，将被迫在"减回购/举债/砍 CapEx"三选**。现金池 $76.8B 可支撑 2–3 年过渡（零债务发行记录是缓冲垫）。**容忍度评估：FY27 内无虞，FY28 起是真正的挤压点**——这与管理层"FCF 为正"承诺的期限一致。

### 5.3 AI 债市场传染路径（外部）

微软是净债权人而非债务人（零新发债），传染通过三渠道：(a) 数据中心生态融资收紧→租户/二线云需求萎缩；(b) 信用事件引发 AI 板块整体估值压缩（Beta 通道）；(c) Nvidia/台积电订单周期反转→供应链库存减值。2026-06-27"AI 泡沫"报道与 BofA 5 月报告显示该叙事已两次测试市场（对应 6 月股价 $373–390 低点）。

## 6. 治理与股权结构

- **结构**：无双重股权，单一普通股，机构持股为主；董事会含独立董事（Stanton 等）。相比 Meta 的创始人控制权集中，微软治理结构更传统、制衡更强。

## 7. 长期确定性：10 年后还在吗？

**回答：在，且大概率更强（生存确定性 90%+，本组合内最高之一）。**
理由：(1) $678B RPO + 2.3 年加权久期的企业年金结构，收入可见性是软件业历史罕见水平；(2) 30M 付费 Copilot 席位×ARPU 的复利路径刚刚开始；(3) 算力+模型+分发+合规的垂直栈完整，且是唯一同时运营 OpenAI/Anthropic/自研 MAI 三条模型路线的超大规模云；(4) 财务 fortress（$76.8B 现金、零新增有息负债、FCF $67B）可穿越 2–3 年的资本周期错配；(5) 10-K 明示的自研硅+多供应商（Nvidia/AMD/Intel/自研）分散了单点技术风险。
**10 年维度的真问题不是生存，而是**：2032 年 OpenAI IP 许可到期后模型层利润归属；以及 $280B+ 算力存量的长期回报率（若 AGI 类应用货币化不及预期，回报率将向公用事业收敛）。这两个问题的答案决定 2035 年微软是"新沃尔玛毛利的新微软"还是"思科化的微软"。

### 8.2 $436 止损评估（裁定）

- **现价距 $436 为 -9.71%，距 8/17 低点 $478.41 仅 8.8% 缓冲**。$436 位于 7/29 财报跳空缺口上沿（$451.1 收盘）下方、6–7 月密集成交区（$390–420）上方——技术上合理。
- **裁定 1：维持 $436 至 10 月底财报，不现在上移**。理由：8/17 型单日 -3.2% 头条冲击两次即可打穿 $455（距现价仅 -5.8%），过早上移会把"噪音止损"变成大概率事件；而 $436 已锁 +30.85%，组合单笔最大回撤风险 0.93%（60 股×$46.87/组合 ~$305K）。
- **裁定 2：采纳"上穿 $520 后上移 $455"**。$520 为 8/10 高点 $506 上方 2.8%（前高突破确认），$455 较 $520 回撤 -12.5%、锁 +36.56%。该规则只在涨幅兑现后收紧风险，不预支。

### 8.3 9.5% 仓位 +44.9% 浮盈：让利润奔跑 vs 催化剂兑现退出

**裁定 3：10 月下旬 FY27Q1 财报前主动减持 10 股（60→50），锁定 ~$4,830 现金；仓位 9.5%→7.9%。** 理由（李录框架下的权衡）：
1. **赔率不对称**：45% 指引已被 7/29 以来 +21.7% 部分定价（§4 弹性数据），财报 EV 计算约 +0.4%/持平（0.60×+5% + 0.25×-3% + 0.15×-12%）——期望不再补偿左尾；
2. **催化剂日历**：FY27Q1 财报（预计 10 月下旬，按惯例推算）同时承载 Azure 45% 兑现、FY27 CapEx 全年数字、OpenAI IPO 进展三重不确定性，是未来 10 周最肥的左尾日；

**财报后分支规则**：
- Azure ≥45%（cc）且 FY27 CapEx 指引增速 ≤+20% 且 FCF 指引为正 → 50 股继续持有至 FY27Q2（1 月下旬），止损规则不变；

- Azure <43% 或 CapEx 指引失控（>$150B 现金口径）或 OpenAI 应收/RPO 出现异常 → 反弹中清仓剩余 50 股，本持仓周期以 +30~45% 收官。

### 8.4 Azure+45% 兑现概率：证据链（10 条）→ 概率 → 赔率 → 行动
