## 六、安全边际判断：巴菲特会在什么价位买入？

### 巴菲特买入价推算

**方法1：保守DCF（未来5年FCF折现）**

假设：
- FY2026-2030 FCF：$100M, $150M, $200M, $250M, $300M（年均+25%）
- 折现率12%（医疗科技公司WACC）
- 永续增长率3%

**计算**：
```
PV(FCF) = $100/1.12 + $150/1.12² + $200/1.12³ + $250/1.12⁴ + $300/1.12⁵
        = $89M + $120M + $142M + $159M + $170M
        = $680M

Terminal Value = $300M × (1+3%) / (12%-3%) = $3.43B
PV(Terminal) = $3.43B / 1.12⁵ = $1.95B

内在价值 = $680M + $1.95B = $2.63B
```

**巴菲特买入价**（50%安全边际）：$2.63B × 0.5 = **$1.32B市值** = **$38/股**

**方法2：净资产倍数法**

- 当前股东权益$494M
- 假设合理P/B 3x（考虑ROE潜力）
- 公允价值：$494M × 3 = **$1.48B** = **$42/股**
- 巴菲特买入价（30%折扣）：**$29/股**

**方法3：同行业低估值锚定**

- 给予P/S 2.5x（成熟期医疗器械公司下限）
- FY2026收入$742M × 2.5 = **$1.86B** = **$53/股**
- 巴菲特买入价（40%折扣）：**$32/股**

### 综合结论：

**巴菲特合理买入价区间**: **$32-$42/股**  
**当前股价$76.13**: **无安全边际，溢价81%-138%**

## 七、核心风险（巴菲特会担心什么）

### 1. **商业模式可持续性存疑**
- NOP（器官运输物流）是重资产模式（自建机队），与巴菲特偏好的"轻资产高ROE"相悖
- 器官移植市场天花板：美国年移植量仅~4万例，TMDX已覆盖大部分肝脏移植（市占率>70%），增长空间有限

### 2. **运营杠杆反转风险**
- Q1收入增21%但净利润跌71%，说明**费用弹性失控**
- 如果收入增速继续放缓至个位数，公司可能重回亏损

### 3. **债务负担加重**
- Q1单季新增$344M飞机租赁债务，Debt/Equity从1.08→1.73
- $460M可转债2028年到期，如股价低迷无法转股，需现金偿还

### 4. **监管与报销风险**
- NOP模式依赖Medicare/Medicaid报销，政策变化可能影响收入
- FDA对器官移植技术监管趋严（如CHOPS新技术审批延迟）

### 5. **管理层执行力待验证**
- CEO Waleed Hassanein强调"多条增长路径"（欧洲扩张、肾脏OCS），但Q1业绩暴雷引发信任危机
- 内部人持股仅3%，机构持股111%（存在大量融券），股东结构不稳定
