## 真实目的（一切参数服务于此）

捕捉 **1-6 个月内可兑现的大额收益**（催化剂/事件驱动），年化目标 **25-30%**，最大回撤容忍 **≤18%**：

- **机会优先**：行业分布是风险预算和搜索罗盘，不是收益目标——强催化剂与分布区间冲突时，优先催化剂，用硬上限+止损管理风险
- **生存前提**：流程不承诺盈利；目标是提高每笔胜率与赔率、把单笔亏损锁在可承受范围（见"风险参数"），靠重复下注积累收益
- **爆发驱动**：超额收益来自"被灰尘掩盖的金子"（来源H爆发股猎手），而非大盘蓝筹的beta——组合中必须有20-30%仓位配置于50-300%上行空间的早期爆发标的
- **市场温度决定攻守**：现金不是固定比例，而是市场温度的函数——高位多留现金等崩，低位全力部署金子（见"现金动态规则"）

### 现金动态规则（v5.0核心新增——市场温度决定攻守）

**原则**：现金比例不是固定参数，而是整体市场温度的函数。高位多留现金等崩盘，低位全力部署"被灰尘掩盖的金子"。

| 市场温度 | 判定信号（≥3个同向=确认） | 现金比例 | 进攻强度 |
|:--------:|---------|:--------:|:--------:|
| **🔴 狂热** | NDX距高点<3% + VIX<14 + 散户FOMO + IPO首日暴涨 | **45-60%** | 只持有不新建，等崩 |
| **🟠 高位** | NDX距高点3-10% + PE>历史80分位 + 广度收窄 | **35-45%** | 只触发价买入，不追 |
| **🟡 中性** | NDX距高点10-20% + PE中位 + VIX 16-22 | **20-30%** | 正常节奏执行 |
| **🟢 低位** | NDX距高点>20% + VIX>28 + 恐慌新闻 + 基金赎回潮 | **8-15%** | 加速部署爆发股 |
| **🔵 恐慌** | NDX距高点>30% + VIX>40 + 流动性危机 | **≤5%** | 全力抄底（all-in金子） |

**判定信号清单（每次执行/portfolio-rebalance和/daily-brief必须实时搜索确认，禁止凭感觉）**：
1. NDX/NVDA距52周高点距离（Yahoo API取）
2. VIX当前水平（搜索"CBOE VIX index today"）
3. 市场广度：S&P 500中>200日均线的股票比例（搜索"S&P 500 percent above 200 day moving average"）
4. CNN Fear & Greed Index（搜索"fear greed index today"）
5. 近1周IPO/SPAC数量与首日涨幅（情绪温度计）

**规则**：
- ≥3个信号指向同一方向 = 确认该档位
- 信号矛盾 = 取保守方向（多留现金）
- 温度档位直接决定：现金下限 + 爆发仓部署速度 + 新建仓审批严格度
- 🔴/🟠档位：新建仓需用户额外确认（"市场高位仍要买入？"）
- 🟢/🔵档位：触发价候选可加速执行（不等下一轮调仓）

### 约束分级（机会优先，风险靠硬上限和止损管）

- **硬约束（🔴强制修正）**：AI总暴露 50-75%/cap 80、非AI对冲 10-15%/cap 20、现金≥当前温度档位下限、**单一非美国家敞口≤15%**（硬上限20%，含中概ADR/港股——地缘/退市/汇率尾部风险）
- **软约束（⚠️仅提示，不强制修正）**：AI核心/爆发仓/AI平台三个子区间——AI内部轮动跟随催化剂与动量，不做会计口径的均值回归
- **战术上浮通道**：某类别满足"≥2个标的双重准入通过"或"现有持仓处于盈利趋势（未触发止损）"时，允许运行至硬上限（而非区间上限）
- **让利润奔跑**：因上涨导致的超配不主动减仓，直至硬上限或出现卖出信号（止损/催化剂兑现/基本面恶化）
- **不为填格子买弱资产**：低配类别若无候选通过双重准入，允许持续低配，报告标注"等待合格标的"

### 减仓优先级规则（v5.0新增——释放现金时砍谁）

**原则**：需要增加现金时，绝不均衡减仓所有持仓。按以下优先级从“最该砍”到“最后砍”排序：

| 优先级 | 标准 | 逻辑 |
|:------:|------|------|
| **第1刀** | 预期收益最低 | 占用资金但贡献最少=机会成本最大 |
| **第2刀** | 收益风险比最差 | 期望/|悲观| < 0.3 = 赔率不够，不值得承担波动 |
| **第3刀** | 不确定性最高 | 二元事件未验证/催化剂不明确/信息不足 |

**绝对不砍**（除非触发止损）：
- 赔率>0.5 且 催化剂<1个月的标的
- 爆发仓中DNA 6条仍全满足的标的
- 处于盈利趋势且未触发移动止损的标的（"让利润奔跑"原则）

**形式化排序**：减仓优先级得分 = 0.5×(1/期望收益排名) + 0.3×(1/赔率排名) + 0.2×(不确定性排名)，得分最高者最先被减。

### 偏离修正规则（只适用于硬约束类别）

- 偏差 ≤5%：✅ 合理，不需要主动修正
- 偏差 5-10%：⚠️ 警告，在后续操作中优先修正
- 偏差 >10%：🔴 必须修正，必须在本轮调仓中制定修正措施
- 上行偏离=让利润奔跑；下行偏离=不为填格子买弱资产（见约束分级）
- AI三个子类别只做⚠️提示（软约束，不触发🔴）
- **硬上限触发**（AI总暴露>70%、单一非美国家>20%等）：必须下一轮调仓减仓至上限以下，不可例外

## 分类规则（v5.0五类确定性判定 + 判例表）

**主规则**（按优先级顺序判定，前一条能定则不启用后一条）：

1. **爆发仓**：满足来源H的DNA 6条画像（收入≥100% YoY + 盈利拐点 + 市值$3-50B + 赛道纯正≥70% + 积压可见 + 覆盖不足）→ **爆发仓**（不论AI/非AI）
2. **AI核心**：AI相关收入占比≥30%，**且** ROIC>30% **且** FCF为正且稳定/增长——已验证的"印钞机"，AI投入已产生回报
3. **AI平台**：CapEx>$80B/年或AI CapEx占收入>20%，**但** FCF被投入压制（归零/暴跌/转负）——仍在"烧钱建基建"阶段，回报未验证
4. **非AI对冲**：主业与AI无直接关联，或AI仅为次要工具；功能是AI回调时的组合保护
5. 仍无法判定 → 归AI敏感度更高类别（保守原则），报告标注"归类存疑"

**AI核心 vs AI平台的核心区分**：
- AI核心 = “已经赚到钱”（ROIC>30% + FCF正 + 增速稳定）
- AI平台 = “正在烧钱等回报”（CapEx巨大 + FCF被压制 + 折旧潮前置）
- 转化规则：AI平台一旦FCF恢复正且ROIC回升>30% → 升级为AI核心；AI核心若ROIC跌破20%或FCF转负 → 降级为AI平台

**爆发仓动态管理**：
- 市值突破$50B → 移出爆发仓，按主规则重新归类（通常归AI核心）
- 收入增速连续2季<50% → 不再符合DNA，启动退出

## 风险参数（短期交易的生存规则）

### 核心仓（AI核心+AI平台）
- **止损**：-12%触发
- **移动止损**：浮盈>15%后止损上移至成本+5%（或20日均线，取高者）
- **单笔风险预算**：仓位×止损距离 ≤ 总资产1%（如止损-12% → 单笔仓位≤8%）

### 爆发仓（v5.0新增）
- **止损**：**-20%**（爆发股日波动±5-10%常态，-12%会被震出）
- **移动止损**：浮盈>30%后止损上移至成本+10%（或20日均线，取高者）
- **单笔风险预算**：仓位×止损距离 ≤ 总资产**1.5%**（如止损-20% → 单笔仓位≤7.5%）
- **单只上限**：8%总资产
- **爆发仓合计上限**：35%
- **退出规则**：收入增速连续2季<50%→减半；市值突破$50B→移出爆发仓归入AI核心；催化剂兑现+无新催化→兑现1/2利润
- **DNA持续验证**：每季度财报后重新检查6条DNA，任何2条不再满足→启动退出

### 通用规则
- **催化剂兑现退出**：事件驱动仓位在催化剂落地后若无新催化剂接续，兑现离场——"买预期、卖兑现"是1-6个月期限的默认纪律
- **基建期成长股**（FCF为负但收入增速>100%+大额合同积压）：单标的≤8%、此类合计≤12%，强制附带止损与催化剂退出计划（无止损计划=禁止纳入）；长期持仓（>6个月）FCF为负=清仓红线
- **AI泡沫破裂应急规则**：纳斯达克100自高点回撤>25%且AI板块领跌 → 市场温度自动切至🔵恐慌档，现金降至≤5%（全力抄底）；但若回撤>40%+流动性危机 → 保留核心持仓（ROIC>30%+FCF稳定），清仓所有FCF为负的爆发仓标的

## 设计假设（每次执行核验；≥2个失效触发设计复审）

- AI平台CapEx是短期投入期（2-3年后FCF反弹）
- 物理瓶颈（CoWoS/HBM/电力）仍是S级瓶颈
- AI软件定价模式未被根本颠覆
- 市场未进入AI泡沫破裂阶段

**提前复审触发条款（v4.1 2026-08-17新增）**：2026年10月底财报波（MSFT FY27Q1+GOOGL Q3+META Q3+TSM Q3同周落地）是"AI平台CapEx投入期"假设的硬验证点——**若 GOOGL Q3 FCF未回正 且 META折旧开始吞噬利润（营业利润率同比下滑主因折旧）→ 提前触发设计复审**（评估AI总暴露带50-65%是否下修），不等2027年2月例行复审。

**设计理由存档**（为什么是这些数字，调参时先读）：
- AI平台 15-20%（cap 25%）（**2026-08-17由20-25%/cap30下调**）：原带与合格供给脱节——可投池实际仅META（靠止损$519维持）+GOOGL（触发≤$295未到价），四轮调仓始终填不满15.5%；META折旧潮2027-28年化$48-65B系结构性、GOOGL回购归零转$49.6B股权融资=投入期安全垫变薄。META反弹或GOOGL触发后仍可经战术上浮通道运行至cap，下调只消除"缺口焦虑"，不封上涨空间
- AI硬件 25-30%（cap 35%）：物理瓶颈是AI趋势中最确定的受益者，硬件"卖铲子"ROIC/FCF质量更高（TSM ROIC 54.6%型）；cap高于区间上限=给战术上浮留通道，但警惕周期性（2022 NVDA -60%）
- AI软件 15-20%（cap 25%）：轻资产+定价权，但面临AI颠覆定价模式的风险
- 非AI价值 15-25%（cap 35%）：AI回调时的组合保护；2000年启示——思科-89%、微软-60%、可口可乐仅-20%
- 现金 动态（v5.0）：不再是固定10-20%，而是市场温度的函数。高位（🟠）40%+现金=免费看跌期权+抄底弹药；低位（🟢）5%现金=全力部署金子。设计理由：28%现金在高位是正确的（当前8月NDX near ATH），在低位是错误的（2022年10月应该all-in）
